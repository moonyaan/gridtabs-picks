# Latitude

- **URL**: https://latitude.so
- **一句话**: 开源 AI 代理可观测性平台，捕获完整轨迹、发现行为模式、在用户遇到问题前主动告警
- **详细说明**: Latitude 专为生产环境 AI 代理设计的监控平台。对 100% 的 trace 进行语义搜索（无采样），自动发现失败模式并聚类，集成 Slack/邮件告警，兼容 OpenTelemetry，支持从真实案例自动生成评估集，提供人工标注工作流。符合 SOC 2 Type II 和 GDPR 合规要求。
- **目标用户**: 构建和部署 AI 代理的工程团队、需要 LLM 可观测性的开发者
- **视觉风格**: 现代简洁，深蓝灰色调，数据可视化为核心
- **主色调**: 深蓝色，灰色调
- **氛围关键词**: AI 监控、代理可观测性、开源、LLM 追踪、生产就绪
- **可归类方向**:
  - 常规: AI 开发工具 / 可观测性 / 监控告警
  - 创意: 给 AI 代理的黑匣子 / 代理行为显微镜
