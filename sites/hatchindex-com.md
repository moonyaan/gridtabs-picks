# Hatch Index

- **URL**: https://hatchindex.com/
- **一句话**: 帮你查询哪家孵化场有你想要的特定家禽品种现货
- **详细说明**: Hatch Index 聚合美国十家孵化场的库存数据，覆盖 422 个鸡与水禽品种，支持按库存状态、最低起订量、蛋壳颜色、物种和用途筛选，每天更新四次价格与现货信息并显示下次孵化日期。网站声明独立运营、不接受任何孵化场付费，定位为客观比价信息源。
- **目标用户**: 后院养禽爱好者、小型养殖户、寻找特定家禽品种的买家
- **视觉风格**: 简洁数据导向布局，突出筛选与表格功能，配有田园风家禽轮播图
- **主色调**: 白色背景 + 深色文字 + 低调点缀色
- **氛围关键词**: 实用、透明、可信、客观、乡野感
- **可归类方向**:
  - 常规: niche-directories / marketplace-tools
  - 创意: weird-and-wonderful-niche-finds
