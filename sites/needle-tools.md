# Needle Engine

- **URL**: https://needle.tools
- **一句话**: 从 Unity/Blender 直接导出全设备可运行的 3D Web 体验，支持 iOS WebXR 无需安装 App
- **详细说明**: Needle Engine 是连接 Unity/Blender 与 Web 浏览器的 3D 出口工具，让开发者直接从熟悉的 3D 软件导出可在任意设备浏览器运行的 3D 互动体验。支持 iOS Safari WebXR，用户无需安装 App 即可体验 AR/VR 内容，大幅降低 3D Web 发布门槛。
- **目标用户**: 3D 开发者、游戏开发者、想做 Web 3D 产品展示的设计师
- **视觉风格**: 展示 3D 实时渲染效果
- **主色调**: 深色高科技感
- **氛围关键词**: 3D Web、Unity、WebXR、AR/VR、无需安装
- **可归类方向**:
  - 常规: 3D Web 开发工具
  - 创意: ai-creative-studio
