# Firecrawl

- **URL**: https://firecrawl.dev
- **一句话**: 把任意网站转成 AI 可读干净 Markdown 的上下文 API，让 AI 代理能搜索、抓取、操控网页
- **详细说明**: Firecrawl 是专为 AI 应用设计的网页内容提取平台，开源（130K+ GitHub stars）。支持搜索网页并抓取全文、将网站转换为结构化 JSON 或 Markdown、用 AI 提示词模拟浏览器交互（点击/滚动/填表），自动处理 JavaScript 渲染，P95 延迟 3.4 秒，比原始 HTML 节省 93% token。集成 MCP 服务器，直接支持 Claude、Cursor、Windsurf。
- **目标用户**: AI 应用开发者、LLM 工程师、构建 RAG 管道的团队、需要大规模网页数据的企业
- **视觉风格**: 现代科技感，暗色背景配亮色强调，代码优先设计
- **主色调**: 深色背景，橙红火焰色调
- **氛围关键词**: AI 基础设施、网页抓取、开发者工具、LLM 就绪、MCP 集成
- **可归类方向**:
  - 常规: AI 开发工具 / 网页数据提取 / LLM 基础设施
  - 创意: 给 AI 的互联网窗口 / 知识注入引擎
