# A Dark Room

- **URL**: https://adarkroom.web.app/
- **一句话**: 从一堆将熄的篝火开始的极简文字生存游戏，逐步展开成完整故事
- **详细说明**: 一款经典的极简文字游戏，从生火开始，逐步展开成资源采集、建造村庄、探索神秘世界三个阶段，带挂机机制，即使不操作也会持续推进。纯文字呈现不做多余画面，把想象空间留给玩家。（注：原域名 adarkroom.com 已过期转为域名出售页，正确地址为 adarkroom.web.app）
- **目标用户**: 喜欢解谜、叙事发现、挂机养成类游戏的玩家
- **视觉风格**: 极致的极简文字界面，无花哨图形，靠文字营造氛围
- **主色调**: 黑白为主的纯文字界面
- **氛围关键词**: 沉思、神秘、耐心、好奇心驱动
- **可归类方向**:
  - 常规: 文字游戏、独立游戏
  - 创意: 一堆将熄的火，燃出一整个世界
