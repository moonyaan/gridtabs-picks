# writui

- **URL**: https://writui.com
- **一句话**: 终端里使用的极简加密 Markdown 写作工具，所有笔记存成单个加密文件
- **详细说明**: 命令行界面的写作应用，强调隐私与简洁，文章以密码加密的方式本地存储为单一文件。支持 Markdown 实时渲染（标题粗体加粗、斜体显示、代码绿色高亮），同时保留纯文本编辑的便利性，适配终端自身的配色和字体。
- **目标用户**: 偏好命令行界面、重视隐私和纯文本工作流的开发者与技术写作者
- **视觉风格**: 极简单栏终端界面，跟随用户终端主题色
- **主色调**: 终端原生配色，代码块绿色高亮
- **氛围关键词**: 朴素、专注、安全、无干扰
- **可归类方向**:
  - 常规: 终端/命令行写作工具
  - 创意: 极简主义工具设计
