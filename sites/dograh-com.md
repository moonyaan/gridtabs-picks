# Dograh

- **URL**: https://www.dograh.com
- **一句话**: 开源的语音AI客服电话机器人平台，对标VAPI的开源替代方案
- **详细说明**: Dograh 是一个开源语音 Agent 平台，支持构建、定制和部署对话式 AI 电话机器人，可自托管部署在私有基础设施上，数据完全不出本地。主打数据主权和合规审计，面向金融、医疗、国防等强监管行业。
- **目标用户**: 需要数据主权和合规审计的企业（金融科技、医疗科技、国防等）、重视厂商独立性的开发团队
- **视觉风格**: 极简科技感，排版干净留白充足，模块化界面，渐进式信息展开
- **主色调**: 白色背景 + 深色文字，紫色/薰衣草色点缀，中性灰
- **氛围关键词**: 自信、专业、可信、去厂商锁定、企业级
- **可归类方向**:
  - 常规: ai-tools / open-source
  - 创意: sovereign-ai-infrastructure
