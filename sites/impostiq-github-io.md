# Impostiq

- **URL**: https://impostiq.github.io
- **一句话**: 免费浏览器社交推理游戏，玩法类似"谁是卧底"找出隐藏间谍
- **详细说明**: 一款基于社交推理机制的多人小游戏，玩家中隐藏一名"间谍"角色，其他人通过讨论和推理找出对方，适合休闲聚会场景在线游玩。
- **目标用户**: 喜欢聚会类社交推理游戏的休闲玩家群体
- **视觉风格**: 简洁现代，适配网页轻量游玩
- **主色调**: 信息有限，推测简约色系
- **氛围关键词**: 悬疑、策略互动、社交推理、免费即玩
- **可归类方向**:
  - 常规: 网页小游戏
  - 创意: 社交推理趣味类
