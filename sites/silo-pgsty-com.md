# Silo

- **URL**: https://silo.pgsty.com
- **一句话**: 社区维护的 MinIO 分支，恢复完整 Web 控制台并持续发布安全补丁的 S3 兼容对象存储。
- **详细说明**: 在 MinIO 社区版被官方归档后，由社区接手维护的替代方案，保留原有 S3 兼容接口和管理控制台，专注安全补丁和稳定性而非功能扩张。主打"Keep the interface. Own the objects."的务实定位。
- **目标用户**: DevOps 工程师、系统管理员、需要自托管对象存储的团队
- **视觉风格**: 现代极简技术风，简洁排版，支持深浅色模式
- **主色调**: 中性白灰黑，克制的强调色
- **氛围关键词**: 务实、可信赖、社区驱动、技术扎实、诚实透明
- **可归类方向**:
  - 常规: 开发工具、自托管、云存储
  - 创意: 开源守护者、极客工具箱
