# ZooData

- **URL**: https://zoodata.ai
- **一句话**: AI Agent 数据层，将任意网页 URL 转为 agent-ready JSON，减少 75% token 消耗
- **详细说明**: ZooData 专为 AI Agent 优化网页数据抓取，将任意 URL 转换为结构化、精简的 JSON 格式，相比原始 HTML 节省 75% token，内置亚马逊/TikTok 等电商竞品情报抓取能力，是 Agent 工作流的网页数据基础设施。
- **目标用户**: AI Agent 开发者、做竞品情报的团队、需要大量网页数据的 LLM 应用
- **视觉风格**: 技术导向，简洁 API 文档风格
- **主色调**: 深色，以数据展示为核心
- **氛围关键词**: Agent数据、精简、结构化、竞品情报、Token节省
- **可归类方向**:
  - 常规: AI 基础设施、开发者工具
  - 创意: Agent 数据加油站
