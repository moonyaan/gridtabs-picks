# Aegisora

- **URL**: https://aegisora-ai.vercel.app/
- **一句话**: 面向 AI Agent 的安全控制平面，实时拦截工具调用防越权与数据泄露
- **详细说明**: Aegisora 作为轻量级 sidecar 代理运行在企业 VPC 内，实时监控并拦截 AI agent 的工具调用与 API 请求，强制执行最小权限原则，防止提示词注入攻击，并生成审计日志。
- **目标用户**: 安全团队、AI 基础设施与平台工程师、DevSecOps 与合规专业人员
- **视觉风格**: 深色科技感界面，终端风格日志展示，简约排版
- **主色调**: 深色调
- **氛围关键词**: 专业、权威、企业级安全、透明可控
- **可归类方向**:
  - 常规: AI 安全与基础设施工具
  - 创意: AI agent 守护者
