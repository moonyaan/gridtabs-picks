# PieterPost MCP

- **URL**: https://www.pieterpost.com
- **一句话**: 让 AI Agent 通过 API 以编程方式发送实体邮件，彻底消除人工邮政操作
- **详细说明**: PieterPost 提供 MCP 服务器和 API，让 Claude、Cursor 等 AI 工具可以直接调用代码发送真实的纸质邮件。只需一个 API 调用，AI Agent 就能把数字内容转化为实体信件寄到世界各地，是 AI 时代「最后一公里」物理通信的有趣解决方案。
- **目标用户**: AI 开发者、需要自动化发送实体通信的企业、有趣创意项目开发者
- **视觉风格**: 简洁现代的 API 服务界面
- **主色调**: 白色邮件感，简洁
- **氛围关键词**: MCP 协议、AI Agent、实体邮件、自动化、API 服务
- **可归类方向**:
  - 常规: AI Agent API 服务
  - 创意: internet-curiosity-museum, solo-founder-back-office
