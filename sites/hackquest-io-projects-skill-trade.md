# Skill Trade

- **URL**: https://www.hackquest.io/projects/Skill-Trade
- **一句话**: 点对点技能交换平台，AI 智能匹配互补技能，用教学换学习机会。
- **详细说明**: Skill Trade 是一个无需金钱交易的技能交换系统，通过 AI 匹配算法把具有互补能力的用户配对，覆盖编程、设计、音乐等多个领域。平台引入代币化机制（结合 Web3.js/Ether.js），用户教学赚取积分、学习消耗积分，构建公平的"以技换技"经济模型。
- **目标用户**: 学生、爱好者、希望通过协作交换建立技能的终身学习者
- **视觉风格**: 简洁现代的界面（基于 React + Tailwind CSS），文字型 logo，极简导航，信息架构清晰（Overview / Checkpoints / Team）
- **主色调**: 现代专业的中性色调（具体信息有限，偏简约风格）
- **氛围关键词**: 公平、社区驱动、协作、技术创新、平等交换
- **可归类方向**:
  - 常规: 技能交换平台 / 教育社区工具
  - 创意: 极简 Web3 社区美学
