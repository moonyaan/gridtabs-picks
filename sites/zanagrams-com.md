# Zanagrams

- **URL**: https://zanagrams.com
- **一句话**: 文字/字谜益智游戏，挑战你从打乱的字母中组出单词的速度和创意
- **详细说明**: Zanagrams 是浏览器端的字谜拼词游戏，通过字母排列组合挑战词汇能力。玩家在限定时间内从给定字母中尽可能多地组出有效单词，适合碎片时间练习英语词汇或纯粹享受文字游戏乐趣。
- **目标用户**: 文字游戏爱好者、英语词汇学习者、碎片时间娱乐用户
- **视觉风格**: 简洁游戏风格
- **主色调**: 中性色调
- **氛围关键词**: 文字游戏、字谜、益智、浏览器小游戏、词汇挑战
- **可归类方向**:
  - 常规: 浏览器游戏 / 文字益智
  - 创意: 字母的可能性游乐场
