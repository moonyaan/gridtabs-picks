# Ledge

- **URL**: https://ledge.sh
- **一句话**: 可运行的 Markdown 笔记工具，代码块能直接执行并实时显示输出结果
- **详细说明**: 为开发者和 DevOps 打造的"可执行笔记本"，支持 Shell、Python、SQL、TypeScript 等多语言代码块一键运行，可远程 SSH 执行、团队协作同步，并能接入 Claude 等 AI agent。
- **目标用户**: 开发者、DevOps 工程师、系统管理员、技术团队
- **视觉风格**: 简洁极简，浅色背景配深色文字，等宽字体展示代码，强调功能性而非装饰
- **主色调**: 白色/浅灰背景，黑色等宽字体
- **氛围关键词**: 极简、技术向、高效、专业、开发者工具
- **可归类方向**:
  - 常规: 开发者生产力工具 / 笔记与文档工具
  - 创意: 技术美学 / 命令行文化
