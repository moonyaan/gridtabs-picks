# Blitzortung Lightning Map

- **URL**: https://lightningmaps.org
- **一句话**: 志愿者众包运营的全球实时闪电打击地图
- **详细说明**: 基于 Blitzortung.org 网络的全球闪电探测地图，由全球各地志愿者自建的接收站实时上传数据，地图上的每个闪光点代表刚刚真实发生的一次闪电打击，非模拟或历史数据。
- **目标用户**: 气象爱好者、开源众包项目关注者
- **视觉风格**: 深色地图背景，明亮闪电点缀
- **主色调**: 深蓝/黑背景配黄白闪光
- **氛围关键词**: 实时、众包、气象、暗色美学
- **可归类方向**:
  - 常规: 气象数据可视化工具
  - 创意: 此刻正在发生系列
