# GitFut

- **URL**: https://gitfut.com
- **一句话**: 把 GitHub 个人资料转换成 FIFA 风格球员卡，用真实提交数据生成"能力值"。
- **详细说明**: 输入 GitHub 用户名即可生成个性化球员卡，把速度、盘带、射门、防守、传球、身体等指标映射到编程活动数据，总评分满分 99，是开发者文化与体育游戏文化的有趣混搭，在开发者圈广泛走红。
- **目标用户**: GitHub 用户、喜欢游戏文化的开发者、想晒代码贡献的人
- **视觉风格**: FIFA Ultimate Team 球员卡美学，高对比度，能量感强
- **主色调**: 金色、深色背景配鲜艳数据条
- **氛围关键词**: 有趣、竞技感、可分享、开发者梗文化
- **可归类方向**:
  - 常规: 开发者工具、数据可视化
  - 创意: 游戏化身份卡、代码变球星
