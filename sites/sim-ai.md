# Sim

- **URL**: https://www.sim.ai
- **一句话**: 开源 AI Agent 工作流搭建平台，用自然语言描述即可生成自动化流程。
- **详细说明**: 提供可视化工作流编辑器，连接各类集成、数据源和大模型，内置知识库、数据表和完整的监控能力，可自托管部署，面向企业团队自动化销售、工程、合规等业务流程。
- **目标用户**: 技术团队、企业自动化负责人、需要自建 AI Agent 工作流的开发者
- **视觉风格**: 现代科技感，蓝色调，模块化工作流图表
- **主色调**: 蓝色系
- **氛围关键词**: 企业级、开源、自动化、可信赖
- **可归类方向**:
  - 常规: AI 开发平台、工作流自动化
  - 创意: 开源 Agent 工坊
