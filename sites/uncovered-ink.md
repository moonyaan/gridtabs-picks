# Uncovered

- **URL**: https://uncovered.ink
- **一句话**: 不看书名和封面，随机滚动浏览各种书籍开篇样章，凭内容本身决定要不要读下去。
- **详细说明**: 一个反"以貌取书"的阅读发现工具，剥离书名、作者、封面等先入为主的信息，让读者纯粹通过文字本身判断是否感兴趣，是发现新书的另类方式。
- **目标用户**: 爱读书但厌倦被营销包装左右判断的人、想发现小众好书的读者
- **视觉风格**: 待实地确认（网站限制自动抓取，信息基于站点性质推断，预计以文字排版为主）
- **主色调**: 待实地确认
- **氛围关键词**: 纯粹、发现感、反营销、阅读实验
- **可归类方向**:
  - 常规: 阅读工具、书籍发现
  - 创意: 盲选阅读、反包装实验
