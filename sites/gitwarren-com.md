# GitWarren

- **URL**: https://gitwarren.com
- **一句话**: 本地运行的代码审查工具，让 AI 编程助手提交修改前先由人审阅并留评论
- **详细说明**: 直接读取开发者本机 git 仓库中已暂存、未暂存和未跟踪的文件变更，在推送到 GitHub 之前进行审查，并支持 AI Agent 参与审查流程留言讨论。强调数据不复制、不中转，只留在用户自己的电脑上。
- **目标用户**: 使用 AI Agent 辅助编程、希望在提交前人工把关代码变更的开发者和团队
- **视觉风格**: 极简技术风，深色/中性调为主，注重 diff 可读性
- **主色调**: 深色背景配色
- **氛围关键词**: 务实、可信、本地优先、开发者直觉
- **可归类方向**:
  - 常规: AI 辅助编程/代码审查工具
  - 创意: -
