# Techno Machine in One HTML File

- **URL**: https://ssx360.github.io/rack-02/
- **一句话**: 单个 HTML 文件实现的可验证音频渲染合成器，纯前端做出一台电子音乐机器。
- **详细说明**: 极客向的音频合成实验项目，整个音序器/合成器完全用一个 HTML 文件实现，展示了浏览器原生音频 API 的能力边界，可以实时调节参数生成 techno 风格电子音乐。
- **目标用户**: 音乐制作人、Web Audio 爱好者、极客程序员
- **视觉风格**: 极简旋钮/推子界面，工业音乐设备美学
- **主色调**: 黑底配霓虹指示灯
- **氛围关键词**: 极客、电子音乐、单文件魔法
- **可归类方向**:
  - 常规: 音乐工具、Web Audio 实验
  - 创意: 一个 HTML 文件里的电子乐机器
