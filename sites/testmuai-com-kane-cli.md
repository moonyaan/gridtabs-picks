# Kane CLI

- **URL**: https://www.testmuai.com/kane-cli/
- **一句话**: 终端里用自然语言描述测试用例，直接在真实 Chrome 浏览器里跑通过/失败验证，无需写选择器。
- **详细说明**: Kane CLI 让开发者用纯英文描述测试步骤，工具驱动真实 Chrome 浏览器执行并返回通过/失败结果，无需编写脆弱的选择器脚本，自动生成测试、留存证据，并可接入 CI/CD 流程，同时面向 Claude、Cursor、Gemini 等 AI 编程智能体提供可靠的浏览器自动化能力。
- **目标用户**: 开发者与 QA 工程师、需要浏览器自动化能力的 AI 编程智能体、实施浏览器端 CI 检查的 DevOps/平台团队
- **视觉风格**: 现代科技感，排版干净留白充足，图标化导航突出工作流阶段，配有实际测试执行的动图演示，还有可爱的吉祥物角色 "Kane" 增添亲和力
- **主色调**: 白与浅灰为主，明亮蓝色作强调色，深藏青/黑色文字，偶有紫色渐变点缀
- **氛围关键词**: 亲和、可靠、技术可信度、高效、专业不失活泼
- **可归类方向**:
  - 常规: 开发者工具 / 自动化测试
  - 创意: 现代科技吉祥物美学
