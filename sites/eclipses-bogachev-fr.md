# Where the Shadow Fell

- **URL**: https://eclipses.bogachev.fr
- **一句话**: 交互式可视化工具，展示公元前 2000 年至公元 3000 年间近 1.2 万次日食的轨迹与规律。
- **详细说明**: 该项目在交互式地球视图上绘制了跨越五千年的 11,898 次日食数据，用户可拖拽旋转、缩放地图，按沙罗周期（Saros，18年11天）和交点周期（Inex，28年345天）筛选日全食、日环食、混合食、日偏食等不同类型，并点击地图选择特定位置查看日食轨迹。集科普教育与天文数据艺术于一体。
- **目标用户**: 天文爱好者、教育工作者、数据可视化爱好者、对天体现象好奇的普通用户
- **视觉风格**: 极简且偏技术向，深色阴影区（本影/半影）与浅色区域形成高对比，几何化的"实墨"全食走廊与"淡彩"偏食晕染，交互带环境音乐反馈，科学严谨中带探索乐趣
- **主色调**: 深色（阴影/本影）与浅色对比为主，星空黑底
- **氛围关键词**: 科学严谨、宇宙感、探索欲、数据艺术、静谧
- **可归类方向**:
  - 常规: 天文数据可视化 / 科普工具
  - 创意: 宇宙数据艺术美学
