# Goblin Tools

- **URL**: https://goblin.tools
- **一句话**: 把让你不知从何下手的大任务拆分成可执行小步骤，ADHD 友好的任务分解神器
- **详细说明**: Goblin Tools 专为执行困难的人设计，核心功能"Magic To-Do"可以把一个模糊的大任务（如"准备搬家"）自动拆解成具体的一步步行动清单，还能帮你重写措辞、估算时间、调整语气。是对 ADHD 人群和有执行困难者格外友好的工具。
- **目标用户**: ADHD 人群、有执行困难的人、任何觉得任务太庞大不知从哪开始的人
- **视觉风格**: 极简卡通风，绿色哥布林主题，轻松无压力
- **主色调**: 绿色调，友好卡通感
- **氛围关键词**: ADHD友好、任务分解、执行力、轻松、无压力
- **可归类方向**:
  - 常规: 生产力工具、任务管理
  - 创意: 专注生活
