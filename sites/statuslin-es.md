# Statuslin.es

- **URL**: https://statuslin.es
- **一句话**: Claude Code 状态栏脚本的社区画廊，可浏览、预览并一键复用他人配置。
- **详细说明**: Statuslin.es 收集开发者为 Claude Code 编写的自定义状态栏脚本，支持按功能（Git、Token 用量、费用、额度）分类，并通过实际代码渲染出实时预览，配色主题、进度条、点状额度计（●◔○）等细节一目了然。每个条目附复制次数与贡献者头像，形成轻量社区生态。
- **目标用户**: 使用 Claude Code 的开发者，尤其是喜欢定制终端界面的极客用户
- **视觉风格**: 信息密度高、终端/等宽字体友好，大量使用 ASCII 方框字符、渐变进度条与点状量表，呈现务实的开发者工具美学
- **主色调**: Claude 品牌赤陶色（terracotta）为主，辅以 Catppuccin Frappé 等暗色主题和中性灰
- **氛围关键词**: 极客、实用主义、终端美学、社区共享、效率感
- **可归类方向**:
  - 常规: 开发者工具 / 效率脚本画廊
  - 创意: 终端极客美学
