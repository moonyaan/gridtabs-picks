# live/jam

- **URL**: https://livejam.conde.workers.dev
- **一句话**: 浏览器内音乐制作工具，支持最多三人实时远程协作编曲
- **详细说明**: 让多位用户同时在线"一起打拍子"，在浏览器中实时协作创作和演奏音乐，无需跨地域限制即可进行音乐即兴合奏（jam session）。
- **目标用户**: 音乐人、制作人、喜欢远程合作创作的音乐爱好者
- **视觉风格**: 简约现代，小写加斜杠的命名风格（live/jam）体现当代科技感
- **主色调**: 未明确
- **氛围关键词**: 协作、即时性、音乐创作、现代科技感
- **可归类方向**:
  - 常规: 协作创作工具 / 音乐制作工具
  - 创意: 实时协作体验设计
