# micasa

- **URL**: https://micasa.dev
- **一句话**: 在终端里管理家庭维护事务的命令行工具，记录维修、项目和承包商信息。
- **详细说明**: Vim 风格模态导航的 CLI 工具，追踪滤芯更换提醒、装修项目进度、报价对比和承包商历史记录，支持本地 LLM 查询消费记录。面向习惯用命令行、想要可搜索结构化家庭记录的极客用户。
- **目标用户**: 偏好命令行工具的技术型房主
- **视觉风格**: 极简 ASCII 艺术风格，复古终端质感
- **主色调**: 黑白单色终端配色
- **氛围关键词**: 极客、复古终端、高效、略带幽默
- **可归类方向**:
  - 常规: 生产力工具、家庭管理
  - 创意: 开发者美学、终端复古
