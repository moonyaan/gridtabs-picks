# Book of Shapes

- **URL**: https://www.bookofshapes.com
- **一句话**: 免费的极简生成式 SVG 图案集合，可在线调节参数并下载用于设计项目
- **详细说明**: 设计师 Nikolaj Sokolowski 创建的矢量图案库，按网格、流动、放射、噪点、等轴、扭曲、有机、物理等类别组织，用户可浏览、收藏并自定义这些程序化生成的几何图案。
- **目标用户**: 设计师、前端开发者、创意工作者
- **视觉风格**: 简洁极简，白色和中性色为主，让图案本身成为视觉焦点，体现数学之美
- **主色调**: 白色、中性灰
- **氛围关键词**: 极简、几何、系统感、现代、设计资源
- **可归类方向**:
  - 常规: 设计资源工具 / 素材库
  - 创意: 生成艺术 / 几何美学
