# CoolDock

- **URL**: https://cooldock.app/
- **一句话**: 与 macOS 原生 Dock 并存的第二程序栏，提供 160 多种实时小组件和自定义布局
- **详细说明**: CoolDock 是原生 Mac 应用，在系统自带 Dock 旁边新增一个可高度自定义的第二 Dock，内置音乐、天气、日历、提醒事项、系统状态、搜索、快速开关等 160+ 实时小组件，也可放置常用应用和文件夹。支持悬浮布局和外观自定义，面向想从 Dock 获得更多功能的创作者、开发者和关注业务指标的创业者。
- **目标用户**: 想提升 Dock 功能性的 Mac 用户，包括追求效率的创作者、开发者和关注营收/分析数据的创业者
- **视觉风格**: 精致、现代、设计感强，强调"美观"的原生 Mac 外观，支持 Backgrounds.Supply 壁纸联动
- **主色调**: 未指定具体色值，整体走现代简洁路线
- **氛围关键词**: 干净、实用、美观、高级感、个性化、俏皮
- **可归类方向**:
  - 常规：Mac 效率工具、桌面增强工具、生产力应用
  - 创意：Mac 美学、个性化桌面、小组件设计
