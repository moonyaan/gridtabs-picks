# ssh.place

- **URL**: https://ssh.place
- **一句话**: 通过 SSH 连接就能一起画画的协作像素画布，无需安装任何客户端。
- **详细说明**: 类似 Reddit 的 r/place，但入口是一条 SSH 命令：连上后即可在 200×60 的共享网格上放置像素，15 秒冷却一次。不需要注册账号，不需要安装软件，纯终端界面配数字色板作画，禁止拼文字，靠社区自发协作拼出图案。
- **目标用户**: 开发者、极客、喜欢命令行和复古网络文化的技术爱好者
- **视觉风格**: 极简终端风，纯文本 ASCII 界面，数字化色板（0-9 共 16 色可选）
- **主色调**: 终端黑底，多彩像素点缀
- **氛围关键词**: 极客、复古、协作、无门槛、社区共创
- **可归类方向**:
  - 常规: 协作工具、终端应用、创意实验
  - 创意: 像素画布、黑客文化、极简互动
