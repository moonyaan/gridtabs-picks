# Ballet

- **URL**: https://www.ballet.dev/
- **一句话**: 用自然语言描述生成可审查代码来自动化跨系统业务工作流的平台
- **详细说明**: Ballet 把用简单英语描述的业务流程转化为可审查、有版本控制的代码，用于处理线索路由、归因、续约等跨多系统的复杂集成。在需要精确性的地方走确定性执行，在需要灵活性的地方引入 Agent 推理，帮助团队摆脱工程排期积压。
- **目标用户**: RevOps、支持运营、产品驱动增长团队，被工程排期卡住的早期自动化需求方
- **视觉风格**: 极简现代，大量留白，分区排版清晰，集成图标以网格小图标展示
- **主色调**: 黑白灰中性色为主，几乎无强调色
- **氛围关键词**: 自信、务实、专业、去工程瓶颈、清晰
- **可归类方向**:
  - 常规: automation / ai-tools
  - 创意: pragmatic-builders
