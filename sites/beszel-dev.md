# Beszel

- **URL**: https://beszel.dev
- **一句话**: 轻量级自托管服务器监控平台，支持 Docker 容器统计、历史数据和告警
- **详细说明**: Beszel 是专为 homelab 和小型团队设计的极轻量服务器监控工具，支持多服务器统一监控、Docker 容器统计、历史数据图表和多渠道告警。单 Docker 命令即可部署，占用资源极少，是 Netdata/Prometheus 的简洁替代选项。
- **目标用户**: 自托管爱好者、homelab 玩家、小型团队运维
- **视觉风格**: 简洁现代的监控仪表盘
- **主色调**: 深色系，数据可视化
- **氛围关键词**: 自托管、服务器监控、轻量级、Docker、homelab
- **可归类方向**:
  - 常规: 服务器监控工具
  - 创意: self-hosted-gems
