# Port22

- **URL**: https://tryport22.com/
- **一句话**: 用手机远程掌控 Mac 上跑的 AI 编程 agent，随时随地批准它的操作。
- **详细说明**: iOS 配套应用，连接 Claude Code、Codex、OpenCode 等本地运行的编程 agent 会话，实时token流传输到手机，支持锁屏和灵动岛状态提示，离开 WiFi 时通过加密中继连接，iCloud 配对无需额外登录。
- **目标用户**: 用 AI coding agent 的开发者，需要远程监控长任务的人
- **视觉风格**: 简洁现代深色系，大留白，堆叠式排版文案
- **主色调**: 深色/现代色调
- **氛围关键词**: 移动办公、AI 编程、端到端加密、随时掌控
- **可归类方向**:
  - 常规: 开发者工具、移动配套应用
  - 创意: AI 时代新工作流、口袋里的编程助手
