# Capacity

- **URL**: https://capacity.so
- **一句话**: 用自然语言描述即可生成可上线运营的完整应用的无代码搭建平台
- **详细说明**: Capacity 让用户用日常对话描述想法，平台通过追问澄清需求，自动生成包含账户系统、登录、支付、数据持久化等功能的可上线应用。设计风格可根据用户偏好在"温暖友好"与"严肃高端"之间切换。
- **目标用户**: 没有编程经验、希望快速构建并上线应用的非技术创业者和创意者
- **视觉风格**: 现代极简，跨设备无缝适配，界面简洁，风格可灵活切换
- **主色调**: 深藏青/炭灰背景 + 白色文字 + 蓝色系点缀按钮
- **氛围关键词**: 乐观、赋能、对话感、高端、无障碍
- **可归类方向**:
  - 常规: no-code-builders / ai-app-generation
  - 创意: idea-to-app-magic
