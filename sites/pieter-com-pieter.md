# WebImage Maker '97 (pieter.com)

- **URL**: https://pieter.com/~pieter/
- **一句话**: Pieter Levels 用复古 Windows 3.11/Netscape 风格界面打造的个人主页与怀旧实验乐园。
- **详细说明**: 一个 1990 年代风格的个人主页，内含可运行的 Windows 3.11 虚拟机模拟器、拨号上网模拟器，以及 AI 文生图工具、IRC 服务器、Minecraft 服务器、Quake 3 浏览器小游戏、FTP 服务器等一系列复古又真实可用的实验项目，还有访客留言簿。
- **目标用户**: 数字怀旧爱好者、独立开发者、复古计算文化爱好者
- **视觉风格**: 刻意做旧的 90 年代 HTML 风格，动图、像素图形、经典网页安全色
- **主色调**: 灰色系、经典 Web-safe 色板
- **氛围关键词**: 复古、俏皮、技术炫技、怀旧博物馆
- **可归类方向**:
  - 常规: 个人主页、复古实验项目
  - 创意: 90年代互联网博物馆、独立开发者游乐场
