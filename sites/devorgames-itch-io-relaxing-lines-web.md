# Relaxing Lines

- **URL**: https://devorgames.itch.io/relaxing-lines-web
- **一句话**: 经典万花尺玩具的数字化版本，转几下就能画出治愈系几何图案
- **详细说明**: 灵感来自传统万花尺（Spirograph）玩具的创意游乐场，从安卓端正式扩展到浏览器 WebGL 版本。只需简单几次点击拖动即可生成错综复杂、令人着迷的几何图案，适合涂鸦解压或为设计寻找灵感，主打「数学与艺术相遇」的平静流动体验。
- **目标用户**: 解压涂鸦爱好者、几何图案迷、设计师找灵感、怀旧玩具粉丝
- **视觉风格**: 流动的几何线条画作，万花尺式对称图案，冥想系简洁界面
- **主色调**: 画布黑底配彩色描线，颜色可自由调节
- **氛围关键词**: 解压治愈、几何美学、怀旧玩具、冥想涂鸦、数学之美
- **可归类方向**:
  - 常规: 创意绘图小工具
  - 创意: 几何解压玩具
