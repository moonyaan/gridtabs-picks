# Write.md

- **URL**: https://writemd.app/
- **一句话**: 外观高度可定制的 macOS 本地 Markdown 编辑器，支持 Vim 模式，无账号无追踪。
- **详细说明**: Write.md 让用户自由调整字体、配色、背景、透明度等界面细节以匹配写作时的心境，而非从预设主题里选择，强调"你的文字，你的空间"。原生 macOS（Apple silicon）应用，本地文件管理、无需账号、不收集数据，面向重视隐私与自主权的写作者。
- **目标用户**: macOS 上的写作者、开发者、注重隐私和个性化工作流的独立创作者
- **视觉风格**: 极简且富有诗意，排版留白充足，文字对齐交替变化，配以用户自定义的多样化编辑器截图（忧郁紫调、大地色系等），展现工具的高度弹性
- **主色调**: 深藏青（#1E1E26）、柔和米白（#EBEBF5）、点缀紫色（#7C83FF）
- **氛围关键词**: 静谧、内省、诗意、个人化、深夜写作感
- **可归类方向**:
  - 常规: 写作工具 / Markdown 编辑器
  - 创意: 个性化极简美学
