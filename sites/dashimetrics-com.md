# Dashi Metrics

- **URL**: https://www.dashimetrics.com/
- **一句话**: 把网站访客和付款实时可视化在3D地球仪上的分析工具
- **详细说明**: Dashi Metrics 是一款以 3D 地球仪呈现的实时分析工具，将网站访客活动和付款事件可视化在地球模型上，让数据监控更直观、更具全局感。整体走"lofi"轻量美学路线，弱化复杂仪表盘的压迫感。
- **目标用户**: 独立开发者、SaaS 创始人、希望直观监控实时流量与收入的运营者
- **视觉风格**: 极简 lofi 美学，以 3D 地球可视化为核心，简约克制、有沉浸感
- **主色调**: 中性深色背景为主，地球与数据点点缀色
- **氛围关键词**: 松弛感、沉浸式、全局视野、轻量、可玩性
- **可归类方向**:
  - 常规: analytics-tools / dashboard-visualization
  - 创意: playful-data-experiences
