# TasmoShelf

- **URL**: https://tasmoshelf.app
- **一句话**: 面向智能家居爱好者的可视化管理与监控工具
- **详细说明**: TasmoShelf 是一款 Tasmota 智能设备控制中心 App，通过本地 Wi-Fi 直连管理刷入 Tasmota 固件的设备，支持设备发现、远程开关、能耗监控、定时任务、Apple Home/Matter 集成与配置备份。无需账号、无需云端、无需 MQTT broker，强调本地化与隐私优先。
- **目标用户**: 刷入 Tasmota 固件的智能家居极客、不想搭建 Home Assistant 服务器的技术型用户
- **视觉风格**: 极简功能主义，结构化分区布局，实用直观，支持深浅双主题
- **主色调**: 中性色调，浅色/深色双主题自适应
- **氛围关键词**: 实用、隐私优先、极客、独立、可控
- **可归类方向**:
  - 常规: smart-home-tools / developer-utilities
  - 创意: swiss-army-knife-sites
