# Capptivo

- **URL**: https://capptivo.com/
- **一句话**: 开源免费的屏幕录制工具，自动跟随光标缩放，做出专业演示视频。
- **详细说明**: 定位为 Screen Studio 和 Cursorful 的开源替代品，具备智能光标跟随缩放、平滑运动插值、画笔标注、自定义光标样式、多种导出比例（横屏/方形/竖屏）等功能，跨平台支持 macOS/Windows/Linux，本地处理不上传服务器。
- **目标用户**: 需要做产品演示视频的开发者、独立创作者、教程制作者
- **视觉风格**: 简洁现代，展示时间轴编辑器和标注工具截图
- **主色调**: 中性色调
- **氛围关键词**: 开源免费、专业演示、本地隐私、效率工具
- **可归类方向**:
  - 常规: 开发者工具、屏幕录制
  - 创意: 开源精神、创作者生产力
