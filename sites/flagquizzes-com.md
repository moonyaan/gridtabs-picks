# Flag Quizzes

- **URL**: https://flagquizzes.com/
- **一句话**: 涵盖国旗、首都、地图、国家轮廓的地理知识问答游戏
- **详细说明**: 免注册即玩的地理教育平台，提供国旗、首都、地图定位、国家形状等多种题型，覆盖全部 197 个国家，附难度分级和连续答对记录，让地理学习变得有竞技感和成就感。
- **目标用户**: 地理爱好者、学生、喜欢益智问答的泛人群
- **视觉风格**: 简洁卡片式布局，白底导航清晰，国旗图案为视觉主体
- **主色调**: 白色为主，深蓝作强调色
- **氛围关键词**: 益智、轻竞技、易上手、进阶感、知识型
- **可归类方向**:
  - 常规: 益智问答、教育学习
  - 创意: 地理小课堂、国旗控福音、全球知识挑战
