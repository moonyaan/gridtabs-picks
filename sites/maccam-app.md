# MacCam

- **URL**: https://maccam.app
- **一句话**: 弥补 macOS 缺失原生相机 App 的空白，免费拍照录像工具
- **详细说明**: Mac 原生相机应用，作为 Photo Booth 的现代替代品，支持内建摄像头、iPhone 隔空相机和外接 USB 摄像头多种输入源，自动同步 iCloud 照片库，重制了49个经典 Photo Booth 特效，还支持双击桌面快捷拍照，前10万用户终身免费。
- **目标用户**: 希望在 Mac 上直接拍照录像的用户，重视 Apple 生态整合的人群
- **视觉风格**: 原生 macOS 26 "Liquid Glass" 半透明设计语言，简洁现代
- **主色调**: macOS系统风格，半透明层叠
- **氛围关键词**: 原生感、简洁、实用主义、Apple生态
- **可归类方向**:
  - 常规: Mac 实用工具 / 摄影工具
  - 创意: 产品补缺型创新
