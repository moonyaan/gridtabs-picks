# Karakeep

- **URL**: https://karakeep.app
- **一句话**: 自托管的「书签一切」应用，用 AI 自动标签整理链接、笔记、图片和 PDF
- **详细说明**: Karakeep 是开源自托管书签管理器，前身为热门项目 Hoarder（GitHub 24,800+ stars）。支持保存链接、笔记、图片、PDF，AI 自动打标签，全文搜索，协作共享列表，RSS 自动收集，浏览器扩展（Chrome/Firefox/Safari），原生移动应用（iOS/Android）。
- **目标用户**: 数字囤积者、内容收集爱好者、隐私优先用户、需要协作书签的团队
- **视觉风格**: 现代简洁，支持深色模式，专注于可用性和可访问性
- **主色调**: 深色主题，中性配色
- **氛围关键词**: 自托管、隐私优先、AI 智能、书签管理、开源
- **可归类方向**:
  - 常规: 书签管理 / 自托管工具 / 知识管理
  - 创意: 数字记忆宫殿 / 个人知识库
