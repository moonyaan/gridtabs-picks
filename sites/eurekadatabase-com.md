# Eureka Database

- **URL**: https://eurekadatabase.com
- **一句话**: 把 Reddit 用户真实抱怨转化为创业机会清单，帮创始人发现市场真实痛点
- **详细说明**: Eureka Database 持续抓取 Reddit 各版块的用户抱怨和痛点帖，经过筛选整理后分类呈现，变成可浏览的创业机会数据库。每一条痛点背后都有真实用户的原始帖子支撑，是发现未被满足需求的实用工具。
- **目标用户**: 创业者、产品经理、独立开发者、寻找市场机会的人
- **视觉风格**: 简洁数据库风格，以痛点卡片为核心展示
- **主色调**: 简洁白色，橙色 Reddit 色调点缀
- **氛围关键词**: 创业机会、用户痛点、Reddit、需求发现、市场研究
- **可归类方向**:
  - 常规: 创业工具、市场研究
  - 创意: 独立创始人后台
