# Is This Tech Dead

- **URL**: https://isthistechdead.com
- **一句话**: 追踪各种技术栈是否已经「死亡」的状态检查器
- **详细说明**: 用幽默的方式展示各种编程语言、框架和技术栈的「死亡」状态，基于 GitHub 活跃度、Stack Overflow 趋势、Google 搜索量等指标综合判断。帮助开发者快速了解某项技术是否还值得学习或使用。
- **目标用户**: 开发者、技术选型决策者、技术趋势观察者
- **视觉风格**: 类医疗/讣告风格，幽默设计
- **主色调**: 黑白红等对比色
- **氛围关键词**: 技术趋势、幽默、开发者工具、决策辅助
- **可归类方向**:
  - 常规: 技术趋势工具
  - 创意: internet-absurdism, ai-on-trial
