# Population Rays

- **URL**: https://imjasonh.github.io/playground/population-rays
- **一句话**: "要走多远才能遇到10万人"的互动人口密度可视化
- **详细说明**: 搜索美国任意地点，工具会以该点为中心画出放射状"花瓣"，花瓣长度代表朝该方向走多远才能覆盖10万人口，直观展现人口密度的方向性差异。支持悬停查看具体方向的详细数据。
- **目标用户**: 城市规划者、人口学爱好者、地图可视化爱好者
- **视觉风格**: 简洁数据可视化界面，花瓣状放射图形，CARTO 地图底图
- **主色调**: 柔和低饱和的数据色调
- **氛围关键词**: 分析感、探索性、有机形态、克制专业
- **可归类方向**:
  - 常规: 数据可视化、人口地图
  - 创意: 把人口密度画成一朵花
