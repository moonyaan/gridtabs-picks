# ABSURD.website

- **URL**: https://absurd.website
- **一句话**: 每月发布一个荒诞概念网站项目，用讽刺科技文化的方式呈现怪诞互动艺术实验
- **详细说明**: ABSURD.website 是一个持续运营的概念艺术项目，自2020年9月起每月发布一个荒诞网站（已积累52+作品）。项目形式多样：讽刺创业文化的伪产品、哲学思考实验、互动游戏等。部分作品对公众开放，部分仅限会员访问，订阅邮件可第一时间获知新作发布。
- **目标用户**: 创意专业人士、艺术爱好者、对科技文化有批判思维的人、互联网怪奇爱好者
- **视觉风格**: 极简主义，缩略图风格，干净排版，俏皮而精致
- **主色调**: 中性色，简洁黑白为主
- **氛围关键词**: 荒诞艺术、概念实验、讽刺科技、互动装置、互联网奇趣
- **可归类方向**:
  - 常规: 艺术项目 / 创意实验 / 互联网文化
  - 创意: 互联网荒诞博物馆 / 每月一次的数字行为艺术
