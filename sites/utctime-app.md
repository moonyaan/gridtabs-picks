# UTCTime

- **URL**: https://utctime.app/
- **一句话**: 实时显示 UTC 时间、ISO 8601 和 Unix 时间戳的简洁网页工具
- **详细说明**: UTCTime 提供程序能想到的所有时间格式（ISO 8601、Unix、RFC 等），每种格式一键复制，还支持时区换算和免费 JSON API，是 worldtimeapi.org 停运后的替代品。
- **目标用户**: 软件开发者、需要可靠 UTC 时间的工程师
- **视觉风格**: 极简技术风，表格化布局，排版清晰易扫读，支持深浅色切换
- **主色调**: 黑白灰中性色，点缀色克制
- **氛围关键词**: 务实、直接、无干扰、开发者友好、可靠
- **可归类方向**:
  - 常规: developer-tools / utilities
  - 创意: single-purpose-tools
