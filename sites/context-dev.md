# Context.dev

- **URL**: https://context.dev
- **一句话**: 一站式网页数据 API，抓取任意 URL 为干净 Markdown 并提取品牌资产
- **详细说明**: Context.dev 提供统一的网页抓取和数据提取 API，支持将任意网页转为 LLM 友好的干净 Markdown/HTML、提取品牌 logo/颜色/字体，以及爬取整站 sitemap。是 AI 应用开发者的网页数据基础设施层，前身为 Brand.dev。
- **目标用户**: AI 应用开发者、全栈工程师、需要网页数据提取的产品团队
- **视觉风格**: 开发者工具风格，简洁文档驱动
- **主色调**: 白色主色，强调 API 文档展示
- **氛围关键词**: API、数据提取、开发者、品牌资产、网页抓取
- **可归类方向**:
  - 常规: 开发者工具、API 服务
  - 创意: AI 基础设施
