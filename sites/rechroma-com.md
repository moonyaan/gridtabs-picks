# Rechroma

- **URL**: https://rechroma.com
- **一句话**: 基于 Oklab/Oklch 色彩空间的调色板生成工具，可从图片取色并一键同步到 Figma 变量
- **详细说明**: Rechroma 利用感知均匀的 Oklab/Oklch 色彩空间，在明度、饱和度、色相维度上生成配色方案。支持从图片或单色提取并推荐和谐配色、生成色阶、检查对比度，并能一键导出到 Figma 变量或 CSS/SCSS 设计令牌，面向设计系统和 UI 开发场景。
- **目标用户**: 设计师和前端开发者，尤其是构建设计系统和界面的团队
- **视觉风格**: 黑白简洁 logo，3D 色彩空间可视化，大色块作为主要视觉元素
- **主色调**: 示例配色涵盖橙棕(#CE5623)、亮蓝(#6391F6)、灰紫(#767CBF)、青色(#44CACC)等
- **氛围关键词**: 表达力强、结构化、精确、创意、和谐、技术感、现代
- **可归类方向**:
  - 常规：设计工具、配色工具、UI/UX 工具、开发者工具
  - 创意：色彩美学、设计系统工具、Oklch 色彩实验
