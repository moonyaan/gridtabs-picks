# GrowthBook

- **URL**: https://www.growthbook.io/
- **一句话**: 开源的A/B测试和特性开关平台
- **详细说明**: GrowthBook 是一个数据仓库原生的实验与特性管理平台，为产品团队提供大规模 A/B 测试、带护栏的安全灰度发布，以及直接基于数据仓库的产品分析洞察。强调开源、可自托管、开发者友好。
- **目标用户**: 工程团队、产品经理、数据分析师、增长团队、AI 原生产品开发团队
- **视觉风格**: 现代科技感，简洁排版，抽象几何插画（圆形、方块、渐变），深色模式高对比
- **主色调**: 深色背景 + 青绿色/青蓝色点缀，黑白灰中性色
- **氛围关键词**: 可信赖、企业级、数据驱动、开发者友好、开放透明、安全稳健
- **可归类方向**:
  - 常规: developer-tools / analytics-tools
  - 创意: open-source-infra-showcases
