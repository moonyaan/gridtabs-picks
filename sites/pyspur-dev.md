# PySpur

- **URL**: https://pyspur.dev
- **一句話**: 开源 AI 代理构建和测试 IDE，可视化工作流 + 测试用例，让工程师 10 倍速迭代代理
- **详细说明**: PySpur 是 YC 支持的开源（Apache 2.0，5.5K stars）AI 代理开发平台。提供拖拽可视化工作流构建器，工程师可以定义测试用例并执行，直观看到 pass/fail 对比差异，快速定位并修复代理失败。支持 Python 代码直接构建、云端或本地部署、JSON 导出版本控制，单个 Python 文件即可添加新工具。
- **目标用户**: AI 工程师、构建 AI 代理的开发团队
- **视觉风格**: 简洁技术风，浅色/深色主题可切换，专业感
- **主色调**: 中性色调，现代简洁
- **氛围关键词**: AI 代理、开源、YC 支持、测试驱动、可视化工作流
- **可归类方向**:
  - 常规: AI 开发工具 / 代理框架 / 测试工具
  - 创意: AI 代理的试验台 / 代理工厂
