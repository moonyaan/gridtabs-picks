# Prelint

- **URL**: https://prelint.com/
- **一句话**: 审查 AI Agent 编写的 PR 是否偏离产品需求文档，按次付费而非按席位
- **详细说明**: Prelint 是面向 AI 生成代码的产品意图守护层，自动审查每个 PR 是否偏离已记录的产品决策，识别业务逻辑变更、合规违规、范围蔓延、战略偏离等六类"AI 漂移"，并能在不打扰工程师的情况下为业务方提供基于规格文档的解答。
- **目标用户**: 使用 AI Agent 生成代码的工程团队，尤其是有复杂业务规则或合规要求的公司
- **视觉风格**: 极简留白，浅色背景配深色文字，专业务实的排版
- **主色调**: 白底为主，克制强调色
- **氛围关键词**: 专业、直接、务实、把关而不官僚
- **可归类方向**:
  - 常规: 开发者工具、AI 工程辅助
  - 创意: 给 AI 写的代码请一位产品经理把关
