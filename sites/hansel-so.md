# Hansel

- **URL**: https://hansel.so/
- **一句话**: 本地运行的 Mac 生产力工具，自动记录一天的工作时间线。
- **详细说明**: Hansel 无需手动记笔记或计时，自动捕捉并整理用户一天的工作活动、会议内容和屏幕时间，帮你回忆做过什么、决策从何而来。按任务而非应用组织时间线视图，强调本地运行、隐私安全。
- **目标用户**: Mac（Apple Silicon，macOS 14+）上的知识工作者，需要更好的工作记录与复盘但不想手动追踪
- **视觉风格**: 干净极简，白色留白为主，配合 Chrome、Figma、Slack、Zoom 等应用图标点缀，编号分区（01-06）介绍功能，时间线以任务为组织单位
- **主色调**: 白、灰、黑等中性色为主
- **氛围关键词**: 专业、轻松、可信赖、高效不焦虑、隐私感
- **可归类方向**:
  - 常规: 生产力工具 / 时间管理
  - 创意: 极简中性美学
