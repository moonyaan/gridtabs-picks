# Anthropeum

- **URL**: https://anthropeum.com
- **一句话**: 每日文化猜谜游戏，玩家需在10件文物中判断其来源地区与年代。
- **详细说明**: 一款考验人类文化认知的每日益智游戏，展示10件跨越5000年人类历史的文物，玩家需要猜测每件文物的产地和年代，并可与其他玩家比较排名，是 Wordle 式每日解谜游戏在历史文化领域的延伸。
- **目标用户**: 历史文化爱好者、喜欢每日解谜游戏的用户
- **视觉风格**: 未能完全通过抓取确认（JS 渲染页面），根据元信息推断为图文并茂的展示型界面
- **主色调**: 未知（待人工确认）
- **氛围关键词**: 益智、文化、每日挑战、好奇心
- **可归类方向**:
  - 常规: 益智游戏、每日挑战
  - 创意: 文物侦探、时空猜谜
