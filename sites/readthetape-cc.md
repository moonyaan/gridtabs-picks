# Read the Tape

- **URL**: https://readthetape.cc
- **一句话**: 每日版"炒股 Wordle"，靠盲猜五张标普500个股走势图挑战直觉
- **详细说明**: 每天开放一局新游戏，玩家盲猜五张匿名走势图的涨跌方向，用虚拟一万美元按"信心等级"下注，还能对比"猴子指数"这个纯随机基准。支持连胜记录、分享战绩卡片和技术指标（RSI/ATR/SMA等）。
- **目标用户**: 想练习盘感的准交易员、金融爱好者、休闲解谜玩家
- **视觉风格**: 极简科技感，克制排版，带一点戏谑幽默（如"猴子指数"）
- **主色调**: 中性色调点缀强调色
- **氛围关键词**: 轻松诙谐、博弈感、每日仪式感、自嘲式专业
- **可归类方向**:
  - 常规: 金融小游戏、每日挑战
  - 创意: 给交易直觉做的 Wordle
