# ScreenCI

- **URL**: https://screenci.com
- **一句话**: 从 E2E 测试自动生成产品演示视频的工具
- **详细说明**: ScreenCI 将端对端测试用例（如 Playwright/Cypress 脚本）转化为精美的产品演示视频，无需手动录屏。开发团队在跑测试的同时自动产出可用于营销的产品演示，大幅节省视频制作时间。
- **目标用户**: 独立开发者、SaaS 创业团队、前端工程师
- **视觉风格**: 现代化 SaaS 工具界面，展示视频预览
- **主色调**: 深色系，专业感
- **氛围关键词**: 自动化、开发者工具、视频生成、测试工程化
- **可归类方向**:
  - 常规: 开发者自动化工具
  - 创意: solo-founder-back-office, make-it-beautiful
