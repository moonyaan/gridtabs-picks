# OpenPanel

- **URL**: https://openpanel.dev
- **一句话**: 开源网站与产品分析平台，结合 Mixpanel 的深度功能和 Plausible 的简洁隐私，可自托管
- **详细说明**: OpenPanel 是隐私优先的开源分析平台，同时具备事件追踪、漏斗分析、用户留存队列、会话回放和收益追踪。GDPR 合规、无 Cookie、支持 Docker 自托管部署，AI 原生通过 MCP 集成 Claude/Cursor，$20/月或免费自托管，无用户数量限制。
- **目标用户**: 开发者、初创团队、独立黑客、需要数据自主权的企业
- **视觉风格**: 现代简洁，支持深浅主题，专业易接近
- **主色调**: 深色背景，蓝色强调色
- **氛围关键词**: 开源分析、隐私优先、自托管、数据主权、Plausible 替代品
- **可归类方向**:
  - 常规: 网站分析 / 隐私工具 / 自托管应用
  - 创意: 不出卖用户数据的数字望远镜
