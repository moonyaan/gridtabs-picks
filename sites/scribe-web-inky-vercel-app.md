# Scribe

- **URL**: https://scribe-web-inky.vercel.app
- **一句话**: 极简语音转文字笔记网页应用，说话即可编辑成文本
- **详细说明**: 浏览器端语音笔记工具，录音后本地存储并转成可编辑文本，无需登录、强调隐私保护。交互极简，按空格键即可开始录制，适合喜欢用语音而非打字记录想法的用户。
- **目标用户**: 喜欢语音输入的用户、需要快速记录想法的人
- **视觉风格**: 极简干净，功能优先，无多余装饰
- **主色调**: 浅色背景配深色文字
- **氛围关键词**: 简单、私密、实验性、随手记录
- **可归类方向**:
  - 常规: 效率工具、语音笔记
  - 创意: 说话就是笔记、极简语音本
