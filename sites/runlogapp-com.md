# Run Log

- **URL**: https://runlogapp.com/
- **一句话**: 简洁的跑步日志记录应用
- **详细说明**: Run Log 是一款专注于"理解你的跑步数据"的记录工具，帮助跑者记录每次训练并回顾分析表现，强调数据的可理解性而非单纯的竞技排名。
- **目标用户**: 跑步爱好者、希望复盘训练数据的健身人群
- **视觉风格**: 极简数据导向，清爽现代排版
- **主色调**: 待考（推测浅色背景配运动感强调色）
- **氛围关键词**: 清晰、内省、实用、专注
- **可归类方向**:
  - 常规: fitness-tools / personal-tracking
  - 创意: weekend-websites-worth-opening
