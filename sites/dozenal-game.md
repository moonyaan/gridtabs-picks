# Dozenal

- **URL**: https://dozenal.game
- **一句话**: 以十二进制运算为核心玩法的每日数字解谜游戏。
- **详细说明**: 提供每日谜题、互动教程和可自定义设置，用简洁几何风格的品牌形象降低数字游戏的门槛，鼓励玩家每天回来挑战一道新题。
- **目标用户**: 解谜爱好者、休闲玩家、对另类进制系统好奇的人
- **视觉风格**: 极简现代，简洁几何 Logo，浅色背景
- **主色调**: 浅色系，清爽配色
- **氛围关键词**: 轻松、每日挑战、几何美学、烧脑小品
- **可归类方向**:
  - 常规: 益智游戏、每日挑战
  - 创意: 数字美学、进制实验
