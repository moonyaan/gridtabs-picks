# Read the Places

- **URL**: https://readtheplaces.com
- **一句话**: 收录 392 部小说中提及的真实地点，做成文学地图
- **详细说明**: 一个开放的文学地图集，把392部小说、298座城市、2105个地点按故事中出现的顺序标注到真实地理位置上。公共领域作品附原文引用，受版权保护的作品说明该地点为何重要，还标注了地点确认的可信度等级。
- **目标用户**: 文学爱好者、学生、喜欢按书籍地点旅行的读者
- **视觉风格**: 清晰简洁的极简美学，排版易读，配色克制不抢内容风头
- **主色调**: 低调中性色调
- **氛围关键词**: 学术严谨、探索欲、文学漫游、地理与故事交织
- **可归类方向**:
  - 常规: 文学工具、地图可视化
  - 创意: 用真实地图"走"完一本本小说
