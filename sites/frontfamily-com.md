# FrontFamily

- **URL**: https://www.frontfamily.com/
- **一句话**: 在 React、Vue、Angular、Svelte 等框架间转换 UI 组件的工具
- **详细说明**: FrontFamily 提供跨 7 个主流 UI 库、219 个人工核对过的组件映射，浏览器内直接转换，无需上传服务器或 API Key。区别于 AI 瞎猜式转换，它诚实标注置信度和行为差异，拒绝虚构不存在的等价组件。
- **目标用户**: 前端开发者、进行框架迁移的团队
- **视觉风格**: 极简技术风，清晰排版，代码为中心的呈现方式
- **主色调**: 黑白灰中性色为主，红色点缀警告与错误状态
- **氛围关键词**: 务实、透明、可信、极客、反炒作
- **可归类方向**:
  - 常规: developer-tools / productivity
  - 创意: honest-utilities
