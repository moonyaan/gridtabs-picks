# Babel (Wikipedia Skyscraper)

- **URL**: https://babel.reppie.org
- **一句话**: 把维基百科每一次编辑变成一块砖，每天生成一座不断长高的摩天大楼。
- **详细说明**: 将维基百科的编辑活动可视化成建筑积木，每发生一次编辑就添加一块砖，用建造/成就的隐喻鼓励人们关注协作知识项目的持续生长。
- **目标用户**: 维基百科编辑者和贡献者、对协作知识项目感兴趣的人
- **视觉风格**: 积木/建筑隐喻的可视化设计，累积感强
- **主色调**: 建筑色调（砖红、灰色系推测）
- **氛围关键词**: 积累、协作、成就感、乐观
- **可归类方向**:
  - 常规: 数据可视化、社区激励
  - 创意: 编辑变建筑、协作之美
