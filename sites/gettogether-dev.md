# GET together

- **URL**: https://gettogether.dev
- **一句话**: 用 GET 请求而非 POST 发帖的极简社交网络，程序员黑色幽默实验。
- **详细说明**: 所有帖子通过 GET 请求创建（280 字符限制，10 秒发帖频率限制），支持点赞和回复线程，无需注册登录，自动过滤脏话和加密货币内容，用技术梗讽刺性地颠覆 Web 标准，界面极简黑白单色排版。
- **目标用户**: 开发者、懂技术梗的极客用户
- **视觉风格**: 极简等宽字体排版，技术感十足
- **主色调**: 黑白单色
- **氛围关键词**: 古怪、反叛、技术幽默、独立精神
- **可归类方向**:
  - 常规: 社交实验、开发者社区
  - 创意: 技术梗黑色幽默
