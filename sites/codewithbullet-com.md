# Bullet

- **URL**: https://codewithbullet.com
- **一句话**: 主打速度的YC背景编程智能体，通过路由分级模型和并行执行大幅提速
- **详细说明**: Bullet 是为速度而生的编程智能体，能将任务路由至合适的模型、进行精准代码搜索以减少上下文占用，并并行执行独立操作来消除延迟。产品理念是"无 GUI 也是同一个智能体"，从桌面延伸到命令行。
- **目标用户**: 使用 AI 辅助编程、对现有工具速度不满的软件开发者与工程师
- **视觉风格**: 极简现代，黑白对比为主，依赖排版层级而非色彩堆砌，技术感十足
- **主色调**: 浅色背景 + 黑色文字，单色为主
- **氛围关键词**: 务实、直接、反炒作、高效、不将就
- **可归类方向**:
  - 常规: ai-coding-agents / developer-tools
  - 创意: speed-obsessed-tools
