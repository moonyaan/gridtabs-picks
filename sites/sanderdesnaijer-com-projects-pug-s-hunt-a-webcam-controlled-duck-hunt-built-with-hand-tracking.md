# Pug's Hunt

- **URL**: https://www.sanderdesnaijer.com/projects/pug-s-hunt-a-webcam-controlled-duck-hunt-built-with-hand-tracking
- **一句话**: 摄像头手势追踪的浏览器版打鸭子游戏，手指比枪瞄准、张嘴射击。
- **详细说明**: Pug's Hunt 复刻经典 FC 游戏《打鸭子》，用手部追踪技术实现浏览器内的手势瞄准和张嘴开枪，支持双手和双人模式。创作者用自己的宠物狗 Rambo 作为吉祥物，起初只是一个周末实验项目，最终演变成完整可玩的作品，兼具技术展示和个人趣味。
- **目标用户**: 复古游戏爱好者、对计算机视觉感兴趣的 Web 开发者、追求新奇互动体验的休闲玩家
- **视觉风格**: 复古像素风游戏画面搭配现代简洁的文档介绍页面，明暗模式切换，怀旧游戏感与当代 Web 设计形成对比
- **主色调**: 浅色简洁底色为主，游戏内为经典像素配色
- **氛围关键词**: 趣味、实验性、怀旧、技术展示、个人温度
- **可归类方向**:
  - 常规: 网页小游戏 / 体感交互项目
  - 创意: 复古像素游戏美学
