# LuaCAD

- **URL**: https://luacad.ad-si.com
- **一句话**: 用 Lua 脚本编写参数化 2D/3D CAD 模型的在线工具。
- **详细说明**: LuaCAD 定位为 OpenSCAD 的升级替代方案，主打"更强大、更一致、更快、易嵌入"，支持浏览器内即开即用的 Studio 界面（无需安装），可导出多种 3D 文件格式并直接渲染 PNG 预览。文档以 Markdown 风格呈现，附带语法高亮的代码示例。
- **目标用户**: 工程师、创客、熟悉编程的开发者、参数化设计与 3D 打印爱好者、OpenSCAD 用户
- **视觉风格**: 极简技术向，纯内容导向、无装饰元素，等宽字体代码块配合语法高亮，界面截图展示实际 Studio 工作区
- **主色调**: 黑白灰为主的中性色，代码高亮辅以标准配色
- **氛围关键词**: 务实、极客、开发者向、精确、去装饰化
- **可归类方向**:
  - 常规: CAD 设计工具 / 开发者工具
  - 创意: 极简技术文档美学
