# Cito

- **URL**: https://cito.fim.ai
- **一句话**: 面向学术论文的语义搜索引擎，按含义而非关键词匹配检索文献。
- **详细说明**: 覆盖 Semantic Scholar 和 OpenAlex 数据库中上亿篇论文，支持免登录搜索和 MCP 接入，方便 AI Agent 直接做文献研究，用语义理解取代传统关键词匹配提升检索质量。
- **目标用户**: 研究者、学者、需要高效检索文献的学生
- **视觉风格**: 极简黑白排版，单色调，注重可读性
- **主色调**: 黑白为主
- **氛围关键词**: 学术、精准、克制、专业
- **可归类方向**:
  - 常规: 学术工具、搜索引擎
  - 创意: 语义检索、研究者利器
