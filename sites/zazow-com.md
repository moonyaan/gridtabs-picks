# Zazow

- **URL**: https://zazow.com
- **一句话**: 浏览器里的算法生成艺术游乐场，调节参数实时生成独特数字画作，无需任何编程基础
- **详细说明**: Zazow 提供六种算法艺术创作工具（Mandelbrot、Plasma、Spiro、Bauhaus、Splatter、Squiggles），在浏览器中实时交互调整参数，即时看到视觉反馈，支持保存分享到社区画廊或下载，有 Combinator 功能进行算法组合创作。风格从分形、螺旋、几何图案到彩虹渐变，各种迷幻视觉效果应有尽有。
- **目标用户**: 数字艺术爱好者、创意玩家、设计师寻找灵感、对生成艺术好奇的人
- **视觉风格**: 鲜艳迷幻，分形螺旋几何图案，彩虹渐变和高对比配色
- **主色调**: 多彩，鲜艳的彩虹色调
- **氛围关键词**: 生成艺术、算法、互动创作、迷幻视觉、浏览器创意
- **可归类方向**:
  - 常规: 创意工具 / 数字艺术 / 浏览器实验
  - 创意: 数学之美游乐场 / 算法调色盘
