# PCjs Machines

- **URL**: https://pcjs.org
- **一句话**: 用 JavaScript 模拟经典电脑硬件，可在浏览器里直接体验70-90年代的老系统和软件。
- **详细说明**: 完整模拟 IBM PC、DEC 小型机、终端、计算器、街机等复古计算设备，作为"计算机保存"项目，让用户无需任何安装即可在浏览器中体验70、80年代的经典系统，兼具怀旧情怀和历史教育价值。
- **目标用户**: 复古计算爱好者、计算机历史研究者、对老系统感兴趣的开发者
- **视觉风格**: 简洁极简的深色/中性排版，内容优先的目录式结构
- **主色调**: 深色/中性调
- **氛围关键词**: 怀旧、保存、教育性、博物馆感、可玩的历史
- **可归类方向**:
  - 常规: 模拟器、计算机历史
  - 创意: 数字考古现场、复古电脑博物馆
