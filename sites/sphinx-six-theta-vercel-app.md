# Sphinx

- **URL**: https://sphinx-six-theta.vercel.app/
- **一句话**: Git hook 工具，在 AI 编程代理的改动被推送前，用问答方式确认开发者真正理解了这次改动
- **详细说明**: Sphinx（npm 包名 sphinx-understand）是一个面向使用 Claude Code、Cursor、Codex 等编程代理的开发者的 Git hook。推送代码前会针对本次改动提出一个问题（比如"出错时会发生什么"），只有答对才能继续推送，目的是防止开发者在不理解 AI 生成代码的情况下盲目合并。MIT 协议开源，通过 npm 安装。
- **目标用户**: 使用 AI 编程代理（Claude Code、Cursor、Codex、OpenCode 等）的开发者，也适用于普通 Git 用户
- **视觉风格**: 极简、开发者工具风格的落地页，终端风格的推送流程演示和问答界面，配有演示 GIF
- **主色调**: 深色终端风格配色（具体色值未知）
- **氛围关键词**: 审慎、克制、教育性、专注理解而非速度
- **可归类方向**:
  - 常规：开发者工具、AI 编程辅助、Git 工具、代码审查
  - 创意：反盲目信任 AI、终端美学、极简开发者工具
