# My Library Events

- **URL**: https://mylibrary-events.com
- **一句话**: 输入美国邮编即可查找附近公共图书馆的免费儿童活动
- **详细说明**: 聚合美国1700多家公共图书馆分馆的免费儿童活动信息，包括故事会、手工和 STEM 活动，支持按城市、邮编或州浏览。界面简洁友好，主打"免费"和"本地可及性"。
- **目标用户**: 有孩子的家长和监护人，寻找本地免费教育活动的家庭
- **视觉风格**: 简洁温馨，书本 emoji 📚 强化文教氛围，导航直白
- **主色调**: 中性友好色调
- **氛围关键词**: 社区感、亲子友好、包容、去门槛化
- **可归类方向**:
  - 常规: 亲子生活工具、本地活动查询
  - 创意: 给孩子找免费好去处的地图
