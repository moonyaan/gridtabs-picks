# Cat Bounce

- **URL**: https://www.catbounce.com
- **一句话**: 点击屏幕让猫咪从天而降弹跳满屏的纯粹解压网站。
- **详细说明**: 没有任何实际功能，单纯就是点一下屏幕就有猫咪掉落弹跳，越点越多，专为无聊时刷两下解压而生，是经典"无用但快乐"类网站的代表。
- **目标用户**: 想要几秒钟解压快乐的任何人、猫咪爱好者
- **视觉风格**: 极简，猫咪弹跳动画为主视觉
- **主色调**: 明快活泼色调
- **氛围关键词**: 解压、无厘头、快乐、纯娱乐
- **可归类方向**:
  - 常规: 解压小游戏、纯娱乐
  - 创意: 无用但快乐、猫咪主题
