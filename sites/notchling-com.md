# Notchling

- **URL**: https://notchling.zopcloud.zop.dev/
- **一句话**: 住在 MacBook 刘海里的小生物，会看鼠标、打盹、帮你叼文件，用身体语言当界面。
- **详细说明**: 把 MacBook 刘海拟人化成一只有表情的小生物：盯着鼠标眨眼、闲置时打盹、拖拽文件时张嘴"吞下"、番茄钟计时、天气和电池状态用表情展示，甚至能显示 Claude Code agent 运行状态。完全通过动画和表情交流，不占用系统资源（<1MB，闲时 CPU <0.5%），免费无遥测。
- **目标用户**: 喜欢桌面有趣味细节、使用 Claude Code 的 Mac 用户
- **视觉风格**: 复古电子宠物（Tamagotchi）风格的拟人化角色设计，克制不打扰
- **主色调**: 未明确（推测简约配合系统主题）
- **氛围关键词**: 可爱、复古电子宠物、身体语言即界面、治愈感
- **可归类方向**:
  - 常规: 桌面小工具、菜单栏工具
  - 创意: 拟人化桌面宠物、趣味交互
