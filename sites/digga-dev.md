# Digga

- **URL**: https://digga.dev
- **一句话**: DNS、RDAP/WHOIS 和子域名查询一站式开发者诊断工具
- **详细说明**: 集成 DNS 查询、RDAP/WHOIS 查询和子域名枚举于一体的现代化网络诊断工具。界面简洁高效，支持多种记录类型查询，帮助开发者和运维人员快速诊断域名和网络相关问题。
- **目标用户**: 开发者、运维工程师、安全研究人员
- **视觉风格**: 极简深色终端风格，数据密集但清晰
- **主色调**: 深色背景，绿色/白色文字
- **氛围关键词**: 开发者工具、DNS 诊断、网络调试、极简高效
- **可归类方向**:
  - 常规: 开发者网络诊断工具
  - 创意: keyboard-people, swiss-army-knife-sites
