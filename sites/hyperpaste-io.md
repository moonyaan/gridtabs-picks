# HyperPaste

- **URL**: https://hyperpaste.io
- **一句话**: 免费开源的 macOS 剪贴板管理器，键盘优先体验，本地隐私优先，像系统原生功能一样顺滑
- **详细说明**: HyperPaste 是 MIT 开源的 macOS 剪贴板历史管理器，通过菜单栏常驻提供即时搜索剪贴板历史。支持识别多种格式（文本、代码、颜色、图片、文件），可固定常用条目，自动排除密码管理器和指定应用，完全本地存储、无遥测、无账号。要求 macOS 15.4+。
- **目标用户**: macOS 用户、键盘重度用户、注重隐私的开发者和创作者
- **视觉风格**: 深色主题，极简原生 macOS 风格
- **主色调**: 深灰，系统 UI 色调
- **氛围关键词**: 键盘优先、隐私本地、开源、macOS 原生、剪贴板历史
- **可归类方向**:
  - 常规: macOS 效率工具 / 剪贴板管理 / 键盘工具
  - 创意: 键盘人的第二记忆 / 隐私优先生产力
