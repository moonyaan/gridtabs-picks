# Inclusive Color Space

- **URL**: https://toneyalexander.github.io/inclusive-color-space/
- **一句话**: 生成多样化肤色的简单算法与色彩空间工具
- **详细说明**: 该项目通过主成分分析构建了一个三维色彩空间（T、U、V 坐标），可程序化生成或手动挑选逼真的肤色，覆盖从深到浅的多种肤色谱系。工具附带方法论图解和数学推导，兼顾技术严谨与包容性表达。
- **目标用户**: 数字艺术家、游戏角色创建工具开发者、关注多样性表达的软件开发者
- **视觉风格**: 极简技术教育风，交互式 3D 可视化配合图解和公式说明
- **主色调**: 棕、褐、赭石色系肤色渐变，避免蓝绿紫色调
- **氛围关键词**: 严谨、包容、教育感、务实、开放
- **可归类方向**:
  - 常规: design-tools / developer-tools
  - 创意: inclusive-design-experiments
