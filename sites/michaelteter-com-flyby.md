# Fly By

- **URL**: https://michaelteter.com/flyby.html
- **一句话**: 复古像素风飞机特技游戏，操控飞机戳气球做特技动作。
- **详细说明**: 独立开发者制作的飞行特技小游戏，戳气球得分并有连击加成，具备真实感的飞行物理（俯仰、油门、失速警告、风力影响），支持触屏和键盘操作，可开启 CRT 扫描线滤镜增强复古街机氛围。
- **目标用户**: 休闲街机游戏玩家、飞行模拟爱好者
- **视觉风格**: 复古街机美学，极简仪表盘 HUD
- **主色调**: 深色背景配明亮 UI 元素
- **氛围关键词**: 复古街机、轻松挑战、怀旧感
- **可归类方向**:
  - 常规: 休闲小游戏
  - 创意: 复古像素美学
