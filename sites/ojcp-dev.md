# OJCP

- **URL**: https://ojcp.dev/
- **一句话**: 面向 AI Agent 可读取职位数据的开放协议
- **详细说明**: OJCP（Open Job Context Protocol）是基于 MCP 构建的开放标准，让 AI Agent 能够发现职位机会、评估匹配度并提交申请。目标是让招聘网站、ATS 厂商、猎头平台的职位数据以标准化方式被 Agent 消费，由联盟共建而非单一厂商主导。
- **目标用户**: AI Agent 开发者、招聘平台、ATS 厂商（Workday、Greenhouse、Lever 等）、猎头机构、发布职位的雇主
- **视觉风格**: 极简技术风，深色背景为主，留白充足，图标化导航配合结构化代码示例
- **主色调**: 深炭黑背景 + 灰白对比色，低饱和度
- **氛围关键词**: 标准化、协作、技术严谨、基础设施感、中立
- **可归类方向**:
  - 常规: developer-tools / ai-infrastructure
  - 创意: agentic-web-protocols
