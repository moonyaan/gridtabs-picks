# Petal

- **URL**: https://petal.live
- **一句话**: 开源免费的屏幕共享与远程控制协作工具，CoScreen 停服后的替代品
- **详细说明**: 由 CoScreen 团队打造的开源应用，支持多人同时共享屏幕并互相远程操控，窗口可自由移动缩放，带标注用户光标，支持持久化房间，可选云端托管或自建 Docker 部署。
- **目标用户**: 远程协作的开发团队、技术团队
- **视觉风格**: 简洁专业，大量留白，中性现代配色，聚焦协作功能展示
- **主色调**: 中性灰、白色
- **氛围关键词**: 专业、协作、开源、极简、技术向
- **可归类方向**:
  - 常规: 远程协作工具 / 开发者工具
  - 创意: 开源文化
