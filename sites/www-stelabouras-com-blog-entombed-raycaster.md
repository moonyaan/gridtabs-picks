# Entombed Raycaster

- **URL**: https://www.stelabouras.com/blog/entombed-raycaster/
- **一句话**: 用1983年雅达利游戏 Entombed 的迷宫算法实现的 Wolfenstein 风格光线投射渲染器，浏览器可玩
- **详细说明**: 复刻经典 Atari 2600 游戏 Entombed 的逐行迷宫生成算法，结合现代光线投射（raycasting）技术打造复古 3D 迷宫探索体验，玩家在算法实时生成的走廊中躲避追击的敌人，带 Backrooms 式压抑氛围，提供 C 语言桌面版和 Three.js 浏览器 demo。
- **目标用户**: 游戏开发者、复古计算历史爱好者、独立游戏玩家
- **视觉风格**: 复古 Wolfenstein 3D 式渲染，刻意营造"后室"(Backrooms)式的不安压抑氛围，极简色调，几何走廊
- **主色调**: 暗色调、低饱和度
- **氛围关键词**: 复古、压抑感、算法艺术、怀旧游戏、极简3D
- **可归类方向**:
  - 常规: 游戏开发技术展示 / 复古游戏
  - 创意: 算法生成艺术 / 怀旧氛围网站
