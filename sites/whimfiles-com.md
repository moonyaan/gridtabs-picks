# Whim Files

- **URL**: https://whimfiles.com
- **一句话**: 极速原生 Mac 文件管理器，9MB 无 Electron，模糊搜索秒开
- **详细说明**: Whim Files 是一款专为 macOS 打造的轻量级文件管理器，使用原生框架构建，体积仅 9MB，完全没有 Electron 的臃肿感。支持快速模糊搜索、键盘优先操作，启动和切换目录速度远超 Finder。
- **目标用户**: Mac 用户、键盘党、喜欢极简高效工具的开发者
- **视觉风格**: 原生 macOS 风格，简洁克制
- **主色调**: 系统级灰白配色
- **氛围关键词**: 极速、轻量、原生、键盘优先、简洁
- **可归类方向**:
  - 常规: Mac 效率工具、文件管理
  - 创意: 键盘党神器
