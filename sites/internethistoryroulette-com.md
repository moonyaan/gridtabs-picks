# Internet History Roulette

- **URL**: https://internethistoryroulette.com
- **一句话**: 转动轮盘随机跳转到 Wayback Machine 存档的 90 年代至 2000 年代老网站。
- **详细说明**: 用复古电视机/CRT 显示器的界面包装 Internet Archive 的 Wayback Machine 随机存档页面，把探索早期互联网变成一场"转盘抽奖"，部分页面无法内嵌需在新标签页打开。
- **目标用户**: 互联网怀旧爱好者、网络历史研究者、对早期网页设计好奇的人
- **视觉风格**: 复古 90-2000 年代美学，CRT 电视框架，模拟调频质感
- **主色调**: 复古电视灰、暖色调
- **氛围关键词**: 怀旧、随机惊喜、数字考古、俏皮
- **可归类方向**:
  - 常规: 互联网历史、随机探索工具
  - 创意: 复古上网体验、数字时间胶囊
