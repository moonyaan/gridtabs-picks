# Nomlings

- **URL**: https://www.nomlings.cc
- **一句话**: 会消耗你 Claude Code session token 的虚拟宠物创意实验
- **详细说明**: 一个把 AI 编程 session 变成养宠物游戏的创意实验——你的 Claude Code session tokens 被「喂」给虚拟宠物 Nomlings。越用 AI 写代码，宠物越健康成长。用趣味游戏化视角重新看待 AI 资源消耗，是极客幽默与创意实验的结合。
- **目标用户**: Claude Code 用户、AI 开发者、喜欢创意实验的极客
- **视觉风格**: 像素风格虚拟宠物，Tamagotchi 复古感
- **主色调**: 绿色像素，复古游戏机风格
- **氛围关键词**: 极客幽默、创意实验、像素风、AI 游戏化、复古感
- **可归类方向**:
  - 常规: 创意实验工具
  - 创意: ai-on-trial, browser-playground, internet-curiosity-museum
