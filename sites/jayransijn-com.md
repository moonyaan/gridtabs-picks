# Jay Ransijn — Playable 3D Portfolio

- **URL**: https://jayransijn.com/
- **一句话**: 把个人简历做成一个可以走进去玩的 3D 世界
- **详细说明**: 设计工程师 Jay Ransijn 用 Three.js 打造的沉浸式作品集网站，访客操控角色在场景中自由走动——可以和狗玩接飞盘、骑自行车、开车兜风，拉动机关还能让乐队现场演奏，撞倒过往公司的 logo 积木。基于 three-mesh-bvh 与 WebSocket 支持多人在线，模型控制在 5.7MB 起，加载极快。
- **目标用户**: 创意开发者、设计工程师、寻找作品集网站灵感的求职者/招聘方
- **视觉风格**: 精致的 3D 低多边形世界，柔和光影反射，游戏化探索式导航
- **主色调**: 自然户外色调，暖阳光影反射
- **氛围关键词**: 游戏化简历、沉浸式 3D、多人在线、精工细作、可玩探索
- **可归类方向**:
  - 常规: 创意开发者作品集
  - 创意: 3D 游戏化个人网站
