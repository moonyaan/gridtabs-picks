# Drawesome

- **URL**: https://benji.org/drawesome
- **一句话**: React 绘图工具栏组件，内置七种画笔和橡皮擦，支持导出 SVG/PNG。
- **详细说明**: 一个"除 React 外零依赖"的绘图工具栏组件，灵感来自 Apple 标注工具的拟物化设计，工具栏能在色板、粗细滑块、缩小圆盘等状态间平滑变形，画笔笔触会随移动速度变细，钢笔笔触还会随方向变化，细节考究又带点幽默感。
- **目标用户**: 需要在应用中加入标注/涂鸦功能的开发者（截图标注、画框批注等场景）
- **视觉风格**: 拟物化设计，参考 Apple 标注工具，支持浅色/深色/自动模式
- **主色调**: 支持浅深色切换，18种内置色板
- **氛围关键词**: 俏皮、专业、精致细节、克制自信
- **可归类方向**:
  - 常规: 前端组件库、开发工具
  - 创意: 标注神器、拟物风画笔盒
