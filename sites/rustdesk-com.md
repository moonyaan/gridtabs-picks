# RustDesk

- **URL**: https://rustdesk.com
- **一句话**: 开源远程桌面工具（Rust 编写），TeamViewer/AnyDesk 的免费替代品
- **详细说明**: RustDesk 是用 Rust 编写的全功能开源远程桌面应用，支持自托管中继服务器，让你在任意设备间远程控制桌面。无需订阅无需付费，可完全脱离第三方服务器运行，保护隐私数据不经过外部服务。
- **目标用户**: 自托管爱好者、IT 支持人员、隐私意识强的用户
- **视觉风格**: 简洁功能性界面
- **主色调**: 蓝白色系，专业感
- **氛围关键词**: 开源、远程桌面、自托管、Rust、TeamViewer 替代
- **可归类方向**:
  - 常规: 远程桌面工具
  - 创意: self-hosted-gems
