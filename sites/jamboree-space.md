# Jamboree

- **URL**: https://jamboree.space/
- **一句话**: 浏览器多人合成器，支持点对点联机和实时光标，可与人一起即兴演奏
- **详细说明**: Jamboree 是一个协作式浏览器合成器，提供振荡器、滤波器、包络、LFO 等核心合成参数，支持最多8人同一房间实时联机，通过分享房间 ID 即可邀请他人一起即兴创作电子音乐。
- **目标用户**: 音乐人、制作人、声音设计师、喜欢协作创作电子音乐的爱好者
- **视觉风格**: 极简功能主义，标签和控件直白清晰，兼顾新手和资深用户
- **主色调**: 现代科技感中性色调
- **氛围关键词**: 邀请感、社交创作、探索性、去门槛化
- **可归类方向**:
  - 常规: 音乐创作工具、协作工具
  - 创意: 陌生人也能一起 jam 的合成器
