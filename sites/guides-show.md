# guides.show

- **URL**: https://guides.show
- **一句话**: 把代码 diff 转换成带章节导览的单个 HTML 文件，可加密分享给他人审查代码改动
- **详细说明**: 创建"Guided Review"交互式代码走读文档，按重要性组织章节，左侧章节导航右侧代码 diff 展示。支持导出为便携文件或加密上传云端分享，特别适配 AI 编程助手（如配合 Plannotator）生成的代码变更审查流程。
- **目标用户**: 需要清晰沟通复杂代码变更的开发团队，尤其是使用 AI 编程助手的团队
- **视觉风格**: 极简技术风，左右分栏布局（章节/diff）
- **主色调**: 白底深色文字，开发者工具常见中性色
- **氛围关键词**: 专业、务实、开发者至上、隐私友好
- **可归类方向**:
  - 常规: 代码审查/开发者协作工具
  - 创意: -
