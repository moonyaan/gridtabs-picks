# Hoppscotch

- **URL**: https://hoppscotch.io
- **一句话**: 开源轻量级 API 调试工具，支持 REST/GraphQL/WebSocket 等多种协议，免注册即可在浏览器里直接测试接口。
- **详细说明**: Hoppscotch 是知名的开源 API 开发生态系统，作为 Postman 等商业工具的轻量开源替代品，覆盖 REST、GraphQL、WebSocket、Socket.IO、MQTT 等多种协议调试场景，支持团队协作、环境变量管理和请求集合组织，强调开箱即用、无需注册即可开始测试接口。
- **目标用户**: 后端/全栈开发者、API 工程师、需要快速调试接口的技术团队
- **视觉风格**: 现代简洁的开发者工具界面，功能分区清晰、面板化布局，强调操作效率
- **主色调**: 品牌绿色为主，搭配深色/浅色双主题
- **氛围关键词**: 开源、轻量、高效、开发者友好、社区驱动
- **可归类方向**:
  - 常规: 开发者工具 / API 测试
  - 创意: 现代开发者工具美学
