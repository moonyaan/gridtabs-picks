# Gitwig

- **URL**: https://gitwig.dev
- **一句话**: 用 Rust 编写的现代终端 Git 界面，支持鼠标操作和多仓库管理。
- **详细说明**: 定位为 SourceTree、lazygit 的现代替代品，支持分支、worktree、stash 管理，具备全局代码搜索和自动刷新的仓库状态追踪，主打"极速响应"的开发者体验。
- **目标用户**: 偏好键盘/终端操作的开发者，管理大型仓库的团队
- **视觉风格**: 深色终端美学，边框式布局，叶子图标点缀
- **主色调**: 深色终端背景，绿色点缀
- **氛围关键词**: 极速、专业、开发者工具、终端美学
- **可归类方向**:
  - 常规: 开发工具、Git 客户端
  - 创意: 终端美学、极客生产力
