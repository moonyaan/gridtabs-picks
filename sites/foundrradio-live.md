# FoundrRadio

- **URL**: https://foundrradio.live
- **一句话**: 虚拟 FM 电台平台，任选88.0-108.0频段，开直播打造属于自己的广播电台
- **详细说明**: 模拟传统 FM 调频拨盘，提供201个虚拟频道供用户认领、命名并直播广播内容，无需专业设备，通过浏览器配置麦克风和电脑音频即可开播，听众无需注册即可收听，标准频率收费5美元。
- **目标用户**: 想做播客/电台主播的创作者、音乐爱好者、业余广播爱好者
- **视觉风格**: 功能性界面，控制室、录音室、电平表等专业广播元素
- **主色调**: 未明确（界面偏功能性展示）
- **氛围关键词**: 怀旧广播、社区感、创作自由、复古未来感
- **可归类方向**:
  - 常规: 内容创作工具 / 社区直播平台
  - 创意: 复古媒介文化 / 声音艺术
