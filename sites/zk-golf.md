# zkGolf

- **URL**: https://zk.golf
- **一句话**: 通过竞技优化零知识证明电路来学习密码学的游戏化挑战平台
- **详细说明**: 以「高尔夫」为比喻的零知识证明学习平台——用最少的「约束」（constraints）完成密码学电路挑战就能获胜。把复杂的 ZK 密码学概念转化为可竞技的游戏，适合想入门 zkSNARK 的开发者。
- **目标用户**: 区块链开发者、密码学学习者、想了解 ZK 技术的极客
- **视觉风格**: 极简代码界面 + 高尔夫球场比喻设计
- **主色调**: 绿白对比，简洁
- **氛围关键词**: 密码学游戏化、零知识证明、技术学习、竞技排行、极客
- **可归类方向**:
  - 常规: 密码学学习工具
  - 创意: keyboard-people, browser-playground
