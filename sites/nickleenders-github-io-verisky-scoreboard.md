# VeriSky Scoreboard

- **URL**: https://nickleenders.github.io/verisky-scoreboard/
- **一句话**: 按过去30天温度、风力、降雨预测准确度给各大天气模型打分排名的看板。
- **详细说明**: 用实测数据客观评判各家天气预报模型的准确率，提供"horizon-adjusted"评分方式，让短期预测权重高于长期预测，帮用户判断该信哪个天气 App。
- **目标用户**: 天气爱好者、气象从业者、想知道该用哪个天气 App 的人
- **视觉风格**: 极简数据表格布局，带方向指示箭头，注重可读性
- **主色调**: 中性色调
- **氛围关键词**: 客观、严谨、科学、评测向、干货
- **可归类方向**:
  - 常规: 数据评测、天气工具
  - 创意: 真相裁判所、榜单控
