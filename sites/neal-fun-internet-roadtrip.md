# Internet Roadtrip

- **URL**: https://neal.fun/internet-roadtrip/
- **一句话**: 全网投票驾驶一辆虚拟汽车在谷歌街景中穿越北美，2025 年上线后持续爆火的集体互动实验。
- **详细说明**: 一辆汽车行驶在真实的 Google Street View 画面里，方向由全网观众实时投票决定该左转还是右转，聊天室里的人一起"开车"探索北美的公路、小镇和风景。没有终点，纯粹的集体漫游体验，因为不可预测性和陌生人共驾的乐趣持续走红。
- **目标用户**: 直播爱好者、公路旅行迷、喜欢集体互动实验的人
- **视觉风格**: 真实街景画面 + 简洁投票 UI 悬浮层
- **主色调**: 街景实拍的自然色调
- **氛围关键词**: 集体决策、公路旅行、不可预测、陪伴感
- **可归类方向**:
  - 常规: 集体互动、虚拟旅行
  - 创意: 全网众筹开的一辆车
