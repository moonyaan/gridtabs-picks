# Claudebin

- **URL**: https://claudebin.com
- **一句话**: 把 Claude AI 对话转换成可分享、可嵌入链接的免费开源工具
- **详细说明**: 面向开发者的实用小工具，能将 Claude（尤其是 Claude Code）会话导出为带唯一 URL 的可分享、可续接的产物，方便嵌入 PR 描述或用于复盘分享编程过程。
- **目标用户**: 开发者、Claude 用户、需要记录和分享 AI 辅助编程过程的人
- **视觉风格**: 极简现代技术风，干净排版
- **主色调**: 黑白灰单色系配少量强调色
- **氛围关键词**: 高效、开发者友好、透明协作、实用主义
- **可归类方向**:
  - 常规: 开发工具、AI 效率工具
  - 创意: AI 对话存档馆、代码故事分享
