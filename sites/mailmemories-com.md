# Mail Memories

- **URL**: https://mailmemories.com
- **一句话**: 从 Gmail 中提取并整理照片的桌面应用
- **详细说明**: Mail Memories 扫描 Gmail 收件箱，自动找出邮件附件和内嵌图片中的照片，整理成相册形式，帮用户找回散落在邮件里多年的珍贵记忆。解决了「重要照片埋在邮件附件里无法找到」的痛点。
- **目标用户**: 重度 Gmail 用户、想整理数字记忆的用户、家庭用户
- **视觉风格**: 清爽温暖的相册风格界面
- **主色调**: 暖白色，照片展示感
- **氛围关键词**: 数字记忆、Gmail 整理、照片管理、情感工具
- **可归类方向**:
  - 常规: 邮件照片整理工具
  - 创意: data-about-your-life, inbox-zero-for-everything
