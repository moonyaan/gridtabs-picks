# The Election Dashboard

- **URL**: https://theelectiondashboard.com
- **一句话**: 538 风格的以色列议会选举数据可视化仪表盘。
- **详细说明**: 聚合民调数据、选举结果与各政党表现指标，用清晰的图表和地图呈现复杂的政治信息，力求中立客观地展示选情走势。
- **目标用户**: 政治分析师、记者、学者、关心以色列政治的公民
- **视觉风格**: 信息导向的简洁界面，清晰的数据层级
- **主色调**: 中性色调，配合政党代表色的图表强调色
- **氛围关键词**: 专业、中立、数据驱动、政治观察
- **可归类方向**:
  - 常规: 数据可视化、政治资讯
  - 创意: 选情仪表盘、公民数据工具
