# ModelHub

- **URL**: https://studio.consciousengines.com/
- **一句话**: Mac 菜单栏应用，一站式发现和管理本地 LLM 模型。
- **详细说明**: ModelHub 解决本地大模型管理碎片化的问题——用户通常要在 Ollama、LM Studio、Hugging Face 缓存等多个工具间切换，而 ModelHub 提供统一菜单栏界面来发现、下载和管理模型，兼容 Ollama、MLX、llama.cpp 等主流本地推理工具，体积仅约 4MB，安装三步完成，主打"零锁定"。
- **目标用户**: 在 Mac 上运行本地 LLM 的开发者和技术型重度用户，注重效率、不愿在多个 GUI 间切换
- **视觉风格**: 极简现代，排版留白充足，暗色/中性配色体现开发者工具调性，配有 Product Hunt 徽章、GitHub 链接及兼容平台 Logo 轮播增强生态可信度
- **主色调**: 暗色/中性灰黑为主
- **氛围关键词**: 务实、极客、轻量、零锁定、技术亲和
- **可归类方向**:
  - 常规: 开发者工具 / 本地 AI 模型管理
  - 创意: 极简开发者美学
