# Number Garden

- **URL**: https://number-garden.com
- **一句话**: 数学格点可视化探索工具，用"花园"隐喻呈现数字规律的生长与关联。
- **详细说明**: 自称"A Brilliant Interactive Pattern System"，通过交互式格点/图案系统展示数字规律，让抽象数学概念以有机、可探索的视觉形式呈现，弱化数学的枯燥感。具体交互细节因页面为动态渲染未能完全抓取，推测支持点击/拖拽调整参数观察图案变化。
- **目标用户**: 数学爱好者、学生、对交互式教育可视化感兴趣的人
- **视觉风格**: 推测为有机生长感的格点/图案可视化，交互式画布
- **主色调**: 推测自然色系，绿色系呼应"花园"主题
- **氛围关键词**: 数学之美、有机生长、探索、益智、宁静
- **可归类方向**:
  - 常规: 数学可视化、教育工具、交互实验
  - 创意: 数字花园、图案艺术、生长美学
