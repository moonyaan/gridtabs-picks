# carrier-explode

- **URL**: https://carrierexplode.com
- **一句话**: 解码并对比 iPhone、Pixel、Galaxy 手机运营商配置文件的数据库工具
- **详细说明**: 提取并比较不同地区、不同机型的运营商设置（APN、VoLTE、WiFi 通话、5G 支持情况等），提供按运营商、国家、功能的多维筛选和对比页面，并开放 JSON API 和 CC0 数据集供社区贡献。
- **目标用户**: 移动开发者、网络工程师、运营商从业者及技术爱好者
- **视觉风格**: 极简技术风，三大平台配色区分（iOS/Pixel/Galaxy）
- **主色调**: 白色背景为主，平台专属点缀色
- **氛围关键词**: 透明、专业、开源协作、技术向
- **可归类方向**:
  - 常规: 技术数据库/开发者工具
