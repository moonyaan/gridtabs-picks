# Ask an Astronaut

- **URL**: https://askanastronaut.issinrealtime.org/
- **一句话**: NASA 员工制作的网站，收录国际空间站宇航员与学生之间数千个问答，寓教于乐
- **详细说明**: 汇集学生向国际空间站宇航员提问的真实问答记录，用轻松好玩的方式呈现太空知识，让公众以第一人称视角了解太空生活和科学探索。
- **目标用户**: 学生、教育者、太空爱好者及对科普内容感兴趣的大众
- **视觉风格**: 简洁直观的教育类排版
- **主色调**: 未详，偏向教育网站常见清爽配色
- **氛围关键词**: 亲切、好奇心驱动、科普、真实
- **可归类方向**:
  - 常规: 科普教育类内容网站
