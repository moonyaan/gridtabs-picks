# Eigendrum

- **URL**: https://baselashraf81.github.io/eigendrum/
- **一句话**: 在屏幕上画出任意形状的鼓面，就能听到它真实敲击时会发出的声音。
- **详细说明**: 用有限元分析求解特征值问题，计算任意几何形状鼓面的振动模态和频率。可手绘轮廓或用极坐标/参数方程生成形状，在不同位置"敲击"听声音，还能对比"同谱异形"的鼓（形状不同但音色相同），灵感来自 Mark Kac 1966 年"能否听出鼓的形状"的经典数学问题。
- **目标用户**: 数学/物理爱好者、声音设计师、科普向极客
- **视觉风格**: 极简技术风，Jost 字体，画布交互为核心
- **主色调**: 中性极简
- **氛围关键词**: 数学之美、声音物理、教育向、极客玩具
- **可归类方向**:
  - 常规: 科普/教育、声音工具
  - 创意: 数学艺术、互动物理实验
