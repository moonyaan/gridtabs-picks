# Wild Static

- **URL**: https://wildstatic.com/
- **一句话**: 一个共享型 AI 实验：所有用户与同一个拥有跨会话持续记忆的 AI 实体对话。
- **详细说明**: Wild Static 不是传统的一对一聊天机器人，而是让所有访客与同一个具备永久记忆的 AI 实体交流，形成一种集体性、档案式的公共对话空间。系统由公共资金池支持运行，用户可共同或单独出资维持公开发言权，创造出经济激励与持续参与的独特机制。
- **目标用户**: 数字实验艺术爱好者、AI 意识与社群动态的探索者、乐于开放式协作互动的极客
- **视觉风格**: 刻意粗粝、极简的界面风格，排版稀疏、功能基础，拒绝精致 UI 惯例，呼应"static（静态噪音）"的实验概念
- **主色调**: 低饱和、朴素的黑白/灰阶为主
- **氛围关键词**: 实验性、沉思式不安、透明与暴露的张力、集体记忆、DIY 极客感
- **可归类方向**:
  - 常规: AI 实验项目 / 社群协作工具
  - 创意: 概念艺术 / 实验性数字装置
