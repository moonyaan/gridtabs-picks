# CSS-DOS

- **URL**: https://css-dos.ahmedamer.co.uk/
- **一句话**: 纯 CSS 实现的80年代 PC 模拟器，可在浏览器里运行 Windows 1.0 和 DOOM 等经典程序
- **详细说明**: 用纯 CSS 技巧还原复古 DOS/早期 Windows 图形界面的视觉与交互效果，让用户在现代浏览器里体验怀旧计算机操作系统的外观和部分功能，是一场纯前端技术的秀技式创意实验。
- **目标用户**: 怀旧计算机爱好者、前端开发者、CSS 技巧爱好者
- **视觉风格**: 复古 DOS/早期 Windows 像素风界面，等宽字体
- **主色调**: 经典 DOS 配色（黑底配绿/琥珀/白字）
- **氛围关键词**: 复古、怀旧、技术炫技、荒诞趣味
- **可归类方向**:
  - 常规: 前端技术演示/CSS 创意实验
  - 创意: 复古计算机美学
