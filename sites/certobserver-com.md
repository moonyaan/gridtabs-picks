# CertObserver

- **URL**: https://certobserver.com
- **一句话**: TLS 证书集中监控和库存管理平台，多端点实时检测，证书到期前多渠道提醒
- **详细说明**: CertObserver 为管理多个 TLS 证书的团队提供集中化监控。功能包括：证书库存管理（支持标签分类和手动/自动更新）、证书透明度（CT）日志监控（发现域名下所有证书）、多协议端点检测（HTTPS/FTPS/SMTPS等）、多通道告警（邮件和 Slack）、团队协作（基于角色的访问控制），还有免费无需注册的 CT 搜索工具。
- **目标用户**: DevOps 团队、安全专业人员、管理多证书的中大型组织
- **视觉风格**: 极简主义，灰色调，专业安全工具感
- **主色调**: 灰白为主，单色系
- **氛围关键词**: TLS 证书、安全监控、DevOps 工具、告警通知、团队协作
- **可归类方向**:
  - 常规: 安全工具 / DevOps / 证书管理
  - 创意: 数字证件的专属看护人
