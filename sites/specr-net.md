# Watch Random Code on MS-DOS IDE

- **URL**: https://specr.net
- **一句话**: 模拟 MS-DOS 风格 IDE 实时"打字"生成随机代码的怀旧可视化网站。
- **详细说明**: 用复古 DOS 界面演绎代码被逐字敲出的过程，纯粹为怀旧和视觉趣味而生，没有实际编程功能，是一个氛围向的桌面装饰型网站。
- **目标用户**: 怀旧极客、喜欢复古电脑美学的人、想要有趣屏保素材的人
- **视觉风格**: 复古 DOS 终端风格，等宽字体，逐字打字动画
- **主色调**: 黑底绿字/蓝字经典 DOS 配色
- **氛围关键词**: 怀旧、极客趣味、复古终端、氛围感
- **可归类方向**:
  - 常规: 视觉玩具、桌面装饰
  - 创意: 复古计算美学、怀旧极客
