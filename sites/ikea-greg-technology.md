# IKEA Complexity Index

- **URL**: https://ikea.greg.technology/
- **一句话**: 给近两万件 IKEA 家具按"组装难度"打分排名的非官方粉丝项目。
- **详细说明**: 用步骤数乘以零件数算出复杂度分数，结合经验数据估算组装耗时，并汇总 IKEA 官网用户评价生成 1-5 分易用度评级，可按品类筛选或只看单页说明书的产品。声明"与 IKEA 无关，只是粉丝作品"。
- **目标用户**: 准备买 IKEA 家具的人、数据可视化爱好者、装修党
- **视觉风格**: 纯文字功能性排版，无多余装饰，加载界面简洁
- **主色调**: 中性无主题色
- **氛围关键词**: 极客粉丝作品、数据驱动、生活小实用、幽默较真
- **可归类方向**:
  - 常规: 生活实用工具、数据可视化
  - 创意: 极客整活、家居避坑指南
