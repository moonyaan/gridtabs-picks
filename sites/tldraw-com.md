# tldraw

- **URL**: https://tldraw.com
- **一句话**: 开发者向无限画布 SDK，可嵌入 React 应用构建协作白板体验
- **详细说明**: tldraw 既是一个独立可用的开源协作白板工具，也是一个开发者 SDK，让你把无限画布能力嵌入自己的 React 应用。以优雅的 API 和扩展性著称，越来越多的 AI 应用将其用作可视化交互层。
- **目标用户**: 开发者、需要白板功能的产品团队、协作工具构建者
- **视觉风格**: 简洁手绘风白板
- **主色调**: 白色画布，简洁工具栏
- **氛围关键词**: 无限画布、协作白板、开源、SDK、开发者工具
- **可归类方向**:
  - 常规: 协作白板与开发工具
  - 创意: swiss-army-knife-sites, keyboard-people
