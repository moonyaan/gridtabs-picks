# Readit

- **URL**: https://wereadit.com
- **一句话**: 简洁的稍后阅读应用
- **详细说明**: 一款专注阅读体验的「稍后阅读」工具，让用户保存感兴趣的网页和文章，在合适时间专注阅读。界面简洁无干扰，专注于内容本身，是 Pocket 和 Instapaper 的简洁替代品。
- **目标用户**: 知识工作者、重度阅读者、内容收集爱好者
- **视觉风格**: 极简阅读界面，内容优先
- **主色调**: 白色/米色，衬线字体，舒适阅读感
- **氛围关键词**: 稍后阅读、无干扰、内容优先、极简主义
- **可归类方向**:
  - 常规: 稍后阅读工具
  - 创意: focused-life, inbox-zero-for-everything
