# Chip Builder

- **URL**: https://select.supply/game/chipbuilder
- **一句话**: 从逻辑门开始搭建一颗可运行 CPU 的浏览器游戏
- **详细说明**: ChipBuilder 是一个教育向互动平台，引导用户从最基础的与/或/非门开始，逐步进阶到电路、CPU 设计（ALU、寄存器）直到编写汇编代码，全程动手"从零造一台电脑"。
- **目标用户**: 学生、计算机爱好者、想理解计算机体系结构底层原理的人
- **视觉风格**: 简洁克制的技术风格界面，内容层级清晰
- **主色调**: 未详细提取，整体简约现代
- **氛围关键词**: 循序渐进、动手学习、极客、平易近人
- **可归类方向**:
  - 常规: 计算机教育工具、互动学习
  - 创意: 从逻辑门亲手造一颗芯片
