# Bento

- **URL**: https://bento.page/slides/
- **一句话**: 整个演示文稿工具塞进一个 HTML 文件里，本地优先、离线可用、AI 原生。
- **详细说明**: 单文件即编辑器、查看器和播放器，支持动画、视频、实时图表；元素跨页共享 ID 可自动做形变过渡动画。无需账号或云存储，JSON 结构可直接被 AI 编程助手读写，也支持端到端加密的实时协作编辑。
- **目标用户**: 追求隐私和轻量的演示制作者、开发者、需要 AI 辅助生成演示的团队
- **视觉风格**: 极简编辑排版，Fraunces + Instrument Sans 字体，四套模板画廊（大胆编辑、暖色极简、暗色沉浸、俏皮贴纸风）
- **主色调**: 因模板而异，整体克制现代
- **氛围关键词**: 本地优先、单文件、AI 原生、极简编辑感
- **可归类方向**:
  - 常规: 生产力工具、演示制作
  - 创意: 极简主义、离线优先、开发者美学
