# Memos

- **URL**: https://usememos.com
- **一句话**: 极轻量自托管时间流笔记，无文件夹无标题，像发推一样记录想法，单 Docker 命令部署
- **详细说明**: Memos 是开源（MIT 协议）自托管的私人时间流笔记应用，用 Go 构建。无需文件夹或模板，直接在时间线上用 Markdown 记录链接、代码片段、日记和想法。支持标签、搜索、任务清单，轻量到可以跑在树莓派上，零遥测零追踪，数据完全自主。
- **目标用户**: 自托管爱好者、隐私优先用户、开发者、研究者、任何想要私人数字日记的人
- **视觉风格**: 极简清爽，专注于可读性，低调内敛的设计
- **主色调**: 浅色为主，简洁中性色
- **氛围关键词**: 自托管、极简主义、私人日记、Markdown、隐私优先
- **可归类方向**:
  - 常规: 笔记工具 / 自托管应用 / 知识管理
  - 创意: 私人思想时间线 / 数字便利贴墙
