# Jelly UI

- **URL**: https://jelly-ui.com
- **一句话**: 为原生 HTML 表单控件带来软体物理弹性效果的 UI 组件库
- **详细说明**: Jelly UI 是一个为表单输入框、按钮、下拉框等原生 HTML 控件添加软体物理动画效果的前端库，让交互瞬间变得生动有趣。无需 Canvas，基于 CSS 和轻量 JS 实现，对现有项目几乎零侵入。
- **目标用户**: 前端开发者、独立开发者、希望提升产品交互趣味性的设计师
- **视觉风格**: 极简，强调动态交互演示，以物理弹性动效为核心卖点
- **主色调**: 白底黑字，高亮色点缀
- **氛围关键词**: 趣味、弹性、物理、交互、轻盈
- **可归类方向**:
  - 常规: 前端工具库、开发者工具
  - 创意: 浏览器交互实验、像素手工
