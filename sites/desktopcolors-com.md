# Desktopcolors

- **URL**: https://desktopcolors.com
- **一句话**: 收录经典操作系统默认桌面纯色背景的怀旧色板归档站。
- **详细说明**: Desktopcolors 系统整理了从 1985 年 Windows 1.0、Amiga 到 2024 年 KDE Plasma 6 各代操作系统自带的纯色桌面背景，每种颜色附带精确 HEX 值、所属系统与年代，支持按流行度、年份、字母排序及卡片/列表视图切换。目前已收录 23 个平台共 203 种颜色，并开放 GitHub 贡献。
- **目标用户**: 复古计算爱好者、UI/UX 设计师、技术历史研究者、怀旧向极客
- **视觉风格**: 极简档案式布局，卡片与列表视图搭配清晰排版，色块本身即主视觉，界面克制不抢戏
- **主色调**: 复古青绿（Windows 95 经典 #008080）、银灰（Windows 3.x）、中蓝（#3a6ea5）等系统怀旧色
- **氛围关键词**: 怀旧、复古计算、档案感、极客情怀、色彩考古
- **可归类方向**:
  - 常规: 设计资源 / 色彩工具
  - 创意: 复古计算美学
