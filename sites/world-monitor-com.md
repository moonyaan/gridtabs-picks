# World Monitor

- **URL**: https://world-monitor.com
- **一句话**: 把全球新闻、股市、冲突、DEFCON 等实时信息聚合在交互地图上的态势感知仪表盘。
- **详细说明**: 基于 GDELT 新闻数据集追踪地缘冲突、抗议、自然灾害、疫情爆发，同时整合航班与船舶实时追踪、股市加密货币行情、预测市场赔率、国际空间站追踪和实时摄像头 OSINT 信号，专业感与紧迫感兼具。
- **目标用户**: 新闻从业者、金融分析师、地缘政治研究者、时事关注者
- **视觉风格**: 数据驱动的现代仪表盘布局，"THE MAP/THE WIRE/THE GLOBE" 分区导航
- **主色调**: 深色科技感配 LIVE 状态强调色
- **氛围关键词**: 实时、紧迫感、信息密集、专业权威
- **可归类方向**:
  - 常规: 信息聚合、数据仪表盘
  - 创意: 沉浸式全球态势可视化
