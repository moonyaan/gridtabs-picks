# Stowaway

- **URL**: https://stowaway.live/
- **一句话**: 实时查看头顶飞过的飞机或卫星，模拟坐在窗边俯瞰地面
- **详细说明**: Stowaway 是一个实时可视化工具，展示此刻正从你所在位置上空飞过的真实飞机和卫星，让你沿着真实地形和实时天气条件"跟随"它们飞行，如同坐在飞机窗边俯瞰大地。
- **目标用户**: 航空爱好者、喜欢仰望天空的普通用户、对实时空中交通感兴趣的人
- **视觉风格**: 极简沉浸式，以真实天空摄影般的画面为主，弱化图形装饰，突出实时天空内容本身
- **主色调**: 落日暖橙金 + 天空冷蓝 + 云雪白 + 大地土色，随实时天气变化
- **氛围关键词**: 静谧、诗意、惊奇感、沉浸、即时性
- **可归类方向**:
  - 常规: real-time-visualization / aviation-tools
  - 创意: window-seat-daydream
