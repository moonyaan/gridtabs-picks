# Dwitter

- **URL**: https://www.dwitter.net/
- **一句话**: 用不超过 140 字符的 JavaScript 代码创作动态视觉效果的极客社区
- **详细说明**: 独特的创意编程社区，用户用严格限制在 140 字符内的 JavaScript 代码在 1920×1080 画布上以每秒 60 次的频率生成实时动画，提供 S（正弦）、C（余弦）等简写函数辅助创作。是代码高尔夫与生成艺术结合的极致体现，社区文化崇尚巧思和极限压缩下的创造力。
- **目标用户**: 创意程序员、算法艺术爱好者、代码高尔夫玩家
- **视觉风格**: 深色背景衬托动画效果，代码片段与画布输出并列展示
- **主色调**: 黑灰背景，动画本身色彩缤纷多变
- **氛围关键词**: 极客、俏皮、社区驱动、极限创造力、技术与艺术交融
- **可归类方向**:
  - 常规: 创意编程、生成艺术
  - 创意: 140 字符里的宇宙、代码高尔夫美术馆
