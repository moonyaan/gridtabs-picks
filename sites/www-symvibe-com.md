# Symvibe（原名 Hypervibe）

- **URL**: https://www.symvibe.com/
- **一句话**: macOS 原生应用，把多个 AI 编程代理的真实终端会话排布在一块可视化画板上统一管理
- **详细说明**: Symvibe（原名 Hypervibe，品牌已更名但产品、账号、订阅保持不变）在一块可视化画板上展示 Claude Code、Codex、Gemini CLI 等多个 AI 编程代理的真实终端控制台，使用用户自己已有的 Agent 订阅而非 API Key。画板支持看板、便签、网页预览卡片和手绘标注，代理图标以贴纸形式呈现，面向在 Apple 芯片 Mac 上并行运行多个编程代理的开发者。
- **目标用户**: 在 Apple Silicon Mac（macOS 14+）上并行使用多个 AI 编程代理的开发者
- **视觉风格**: 画板/看板式工作区，手绘标注风格，代理图标做成贴纸质感，兼具技术感和趣味性
- **主色调**: 未知具体色值
- **氛围关键词**: 有条理、技术感、俏皮、本地优先、动手实践、"指挥所"感、掌控感
- **可归类方向**:
  - 常规：AI 编程工具、开发者生产力工具、终端管理工具
  - 创意：多代理协作可视化、画板式工作流、手绘美学
