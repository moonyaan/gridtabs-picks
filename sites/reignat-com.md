# Reignat

- **URL**: https://reignat.com
- **一句话**: 面向独立开发者的隐私优先 Web 分析工具，无 Cookie、无跨站追踪，一行脚本接入
- **详细说明**: Reignat 是轻量级网站分析平台，专为独立开发者设计，无 Cookie、不追踪跨站用户、完全 GDPR 合规。一行脚本接入，提供关键访问指标而不牺牲访客隐私，是 Google Analytics 和 Plausible 的简洁替代。
- **目标用户**: 独立开发者、隐私意识强的站长、SaaS 创业团队
- **视觉风格**: 简洁现代的分析仪表盘
- **主色调**: 浅色系，清爽易读
- **氛围关键词**: 隐私优先、无 Cookie、轻量级分析、独立开发者
- **可归类方向**:
  - 常规: 网站分析工具
  - 创意: solo-founder-back-office
