# Ponytail

- **URL**: https://ponytail.dev/
- **一句话**: 让 AI 编程 agent 优先复用已有代码、把写新代码当最后手段的极简主义规则集。
- **详细说明**: 七步决策阶梯强制 YAGNI 优先原则，提供 lite/full/ultra 三种强度模式和 `/ponytail-review`、`/ponytail-audit` 等命令，官方测试显示可减少 54% 代码量、22% token 消耗，支持 Claude Code、Copilot CLI、Gemini 等 14+ 种 AI agent。
- **目标用户**: 使用 AI 编程助手、想减少代码臃肿和技术债的开发者
- **视觉风格**: 极简科技感，戴眼镜扎马尾的呆板资深程序员吉祥物形象
- **主色调**: 深色模式为主，单色技术感
- **氛围关键词**: 不羁、实用主义、自嘲幽默、极简代码哲学
- **可归类方向**:
  - 常规: 开发者工具、AI 编程辅助
  - 创意: 开发者幽默、极简哲学
