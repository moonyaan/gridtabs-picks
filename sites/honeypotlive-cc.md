# Honeypot Live

- **URL**: https://honeypotlive.cc
- **一句话**: 实时观看机器人与 SSH 蜜罐交互过程的互联网安全可视化工具
- **详细说明**: Honeypot Live 在浏览器里直播真实黑客攻击的过程——真实服务器上的 SSH 蜜罐捕获的攻击行为被实时可视化呈现，你能看到来自全球的机器人尝试登录的过程、输入的命令和探测行为。
- **目标用户**: 安全爱好者、开发者、对互联网背景威胁感兴趣的普通人
- **视觉风格**: 终端黑客风，绿色文字流，实时数据感
- **主色调**: 黑色背景、绿色文字
- **氛围关键词**: 安全、蜜罐、实时、黑客、互联网背景辐射
- **可归类方向**:
  - 常规: 网络安全、开发者工具
  - 创意: 互联网好奇博物馆、一直在线的互联网
