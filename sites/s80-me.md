# S80

- **URL**: https://s80.me/
- **一句话**: 同时测试到 Google、Amazon、Cloudflare 三大服务的网络延迟，快速定位是网络问题还是目标问题。
- **详细说明**: 网页版 HTTP 延迟测试工具，同时向多个知名端点发送请求，展示每个端点的最小/最大/平均延迟，可自定义超时时间和请求间隔，也提供命令行版本。
- **目标用户**: 开发者、网络排障人员、自建服务器运维
- **视觉风格**: 功能性极简界面
- **主色调**: 中性色调
- **氛围关键词**: 极客工具、网络诊断、简单直接
- **可归类方向**:
  - 常规: 开发者工具、网络诊断
  - 创意: 极简实用主义
