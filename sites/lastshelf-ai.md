# LastShelf

- **URL**: https://lastshelf.ai
- **一句话**: 帮你整理好身后事，把账号密码保险信箱遗愿全交代给家人的数字遗产规划平台
- **详细说明**: LastShelf 引导你回答 8 个关键问题，记录文件存放位置、账户访问方式、医疗意愿、紧急联系人、保险细节和账单清单。自动扫描邮件和银行对账单发现遗漏账单，与 1Password 集成安全共享密码，生成家人看得懂的分步操作指南。创始人因父亲确诊癌症而打造这款工具。
- **目标用户**: 有家庭有积蓄的成年人，担心自己突然消失后家人不知道如何处理后事
- **视觉风格**: 温暖克制，不煽情，像一本认真整理过的家庭文件夹
- **主色调**: 暖米色、深绿、沉静蓝
- **氛围关键词**: 责任感、温暖、严肃但不压抑、隐私、家庭
- **可归类方向**:
  - 常规: 数字遗产规划 / 家庭理财工具
  - 创意: "给你爱的人留下的用户手册"
