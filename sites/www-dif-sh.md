# Dif.sh

- **URL**: https://www.dif.sh/
- **一句话**: 把功能开关和 A/B 测试以 Markdown 文件形式存进代码仓库，AI 编程助手可直接读写。
- **详细说明**: 每个实验对应仓库里一个 .md 文件（YAML frontmatter 配置），提供 CLI 创建/校验/结束测试，自动检测冲突和互斥分组，生成 context.json 供 AI coding agent 使用，也可选配云端仪表盘做团队可视化。
- **目标用户**: 使用 AI 编程助手、希望实验管理融入现有 Git 工作流的开发团队
- **视觉风格**: 现代极简，浅色背景配深色代码块，大量命令行示例
- **主色调**: 黑白为主的技术感配色
- **氛围关键词**: 开发者友好、极简、Git 原生、AI 协作
- **可归类方向**:
  - 常规: 开发者工具、A/B 测试
  - 创意: 开发者美学
