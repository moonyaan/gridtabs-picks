# The Quiet Map

- **URL**: https://thequietmap.org
- **一句话**: 用地震仪测算并展示地球上最安静的地点
- **详细说明**: 实时监测全球约100个地震仪站点，测量"人类频段"（4-14Hz）的地面振动，每小时计算出相对自身历史基线而言最安静的地点，用热力图形式呈现全球人为噪音分布，数据来自全球地震台网。
- **目标用户**: 地球科学爱好者、地震学研究者、数据可视化爱好者
- **视觉风格**: 极简沉思风格，用"安静""嗡鸣"等描述性词汇营造诗意，仪表盘式界面
- **主色调**: 克制的科学感配色
- **氛围关键词**: 静谧、诗意、科学严谨、冥想感
- **可归类方向**:
  - 常规: 数据可视化、地球科学工具
  - 创意: 倾听地球的心跳
