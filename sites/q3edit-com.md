# Q3Edit

- **URL**: https://q3edit.com
- **一句话**: 在浏览器里直接编辑和试玩 Quake 3 Arena 地图
- **详细说明**: Q3Edit 是纯浏览器版的 Quake III 地图编辑器，用 TypeScript + WebGL2 打造编辑器，并把 id Software 的 q3map 编译成 WebAssembly，支持实时编辑、BSP 编译和游戏内测试，无需安装任何专业软件或游戏本体。
- **目标用户**: 游戏关卡设计师、Quake III 模组爱好者、复古游戏开发爱好者
- **视觉风格**: 经典四视图编辑器布局，专业级工具感，深色中性配色
- **主色调**: 深色调为主
- **氛围关键词**: 怀旧游戏文化、专业工具感、极客、免安装
- **可归类方向**:
  - 常规: 游戏开发工具、地图编辑器
  - 创意: 把经典FPS的关卡编辑器搬进浏览器
