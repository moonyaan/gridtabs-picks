# TerminalWidget

- **URL**: https://terminalwidget.app/
- **一句话**: 把终端命令输出变成 Mac/iPhone 桌面小组件，进度条、图表、稀疏图应有尽有。
- **详细说明**: macOS 和 iOS 应用，可将文本、进度条、图表、稀疏图、表格、图片等格式化输出直接推送到桌面和锁屏小组件，支持命令行、Shortcuts、AppleScript 或 URL scheme 触发更新，iCloud 跨设备同步，一次性付费 19.99 美元，强调原生轻量无需 Electron。
- **目标用户**: 开发者、需要可视化脚本输出的极客、桌面小组件爱好者
- **视觉风格**: 简约等宽字体，终端美学，绿色强调成功状态
- **主色调**: 中性色+绿色点缀
- **氛围关键词**: 原生轻量、终端美学、极客效率、可视化输出
- **可归类方向**:
  - 常规: 开发者工具、桌面小组件
  - 创意: 极客美学、命令行可视化
