# Woxi

- **URL**: https://woxi.ad-si.com
- **一句话**: 开源的 Mathematica/Wolfram 语言重新实现网页版
- **详细说明**: Woxi 是用 Rust 实现的 Wolfram 语言解释器，可直接在浏览器本地运行，无需联网、无需安装，数据不外传。提供网页版 Playground、命令行工具、Jupyter 内核和原生笔记本编辑器多种使用方式。
- **目标用户**: 开发者、数据科学家、科研人员、熟悉 Wolfram 语言但不想用重量级 Mathematica 的用户
- **视觉风格**: 极简技术风，大量留白，代码与输出并排展示，注重功能性而非装饰
- **主色调**: 黑白灰为主，低饱和度截图，几乎无强调色
- **氛围关键词**: 极客、轻量、本地优先、专业、开放
- **可归类方向**:
  - 常规: developer-tools / open-source
  - 创意: nerdy-utilities
