# Cursor Camp

- **URL**: https://neal.fun/cursor-camp/
- **一句话**: 无聊天、无用户名的多人在线小天地，你和其他访客只以光标形式出现，一起探索露营地、游泳、跳舞。
- **详细说明**: Neal Agarwal 出品的实时多人互动小站，抛弃了所有社交媒体式的身份标识（用户名、头像、聊天框），只留下最原始的"另一个光标存在于同一个空间"的陌生人共处感。可以一起在营地散步、跳舞、生篝火，营造出一种安静又神奇的集体在场体验。
- **目标用户**: Neal.fun 粉丝、喜欢氛围感网页玩具的人、社交媒体倦怠人群
- **视觉风格**: 手绘像素风露营场景，柔和暖色调
- **主色调**: 篝火橙、夜空深蓝
- **氛围关键词**: 陌生人共处、无社交压力、治愈、氛围感
- **可归类方向**:
  - 常规: 多人互动、氛围体验
  - 创意: 无社交压力的陌生人共处
