# CostPerPrompt

- **URL**: https://costperprompt.com
- **一句话**: AI API 调用成本对比计算器，覆盖 292 个模型的实时定价数据。
- **详细说明**: 聚合各大厂商 AI 模型的实时价格，并提供专项计算器，结合 prompt 缓存、批量处理折扣等因素精确估算实际花费。相比笼统的价目表，能避免估算误差高达 2-3 倍的问题。
- **目标用户**: 开发者、工程师、产品经理及需要评估和优化多平台 AI 支出的团队
- **视觉风格**: 极简技术风，以美元符号 "$_" 为标志性图标，注重数据可读性
- **主色调**: 中性专业色调，黑白灰为主
- **氛围关键词**: 实用、精准、务实、数据驱动、省钱
- **可归类方向**:
  - 常规: AI 工具、计算器、开发者工具
  - 创意: 极客理财、数字精算、成本透明化
