# OpenSEO

- **URL**: https://openseo.so
- **一句话**: 开源 Ahrefs/Semrush 替代品，含关键词研究/排名追踪/反链/站点审计和 MCP 接口
- **详细说明**: OpenSEO 是覆盖完整 SEO 工作流的开源平台，提供关键词研究、搜索排名追踪、反向链接分析、站点技术审计，以及 AI 品牌可见度追踪。可自托管免费使用，订阅仅需 $10/月，并内置 MCP server 让 AI Agent 直接查询 SEO 数据。
- **目标用户**: 独立开发者、SEO 从业者、需要降低 SEO 工具成本的初创团队
- **视觉风格**: 简洁的 SaaS 工具风格，数据看板为主
- **主色调**: 绿色调，专业数据感
- **氛围关键词**: 开源、SEO、自托管、低成本、AI集成
- **可归类方向**:
  - 常规: SEO 工具、开发者工具、自托管
  - 创意: 独立创始人后台
