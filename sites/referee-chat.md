# Referee.Chat

- **URL**: https://referee.chat/
- **一句话**: 让多个 AI 互相辩论、由裁判 AI 仲裁得出结论的严谨决策工具
- **详细说明**: Referee.Chat 让用户设定一个问题或目标，多个大模型作为辩手在多轮中互相论证，另有一个裁判模型依据预设标准（如专家级、发表级、形式证明级）判断论证质量并决定何时结束。内置 arXiv、OpenAlex 等文献检索与 Python 算术校验，用于提升论证的证据可信度。
- **目标用户**: 研究者、需要决策级证据的专业人士、追求严谨论证的学术人群
- **视觉风格**: 极简文字优先排版，层次清晰，留白充足，克制不花哨
- **主色调**: 黑白灰中性色系
- **氛围关键词**: 严谨、学术、理性、克制、权威
- **可归类方向**:
  - 常规: ai-tools / decision-making-tools
  - 创意: weird-and-wonderful-ai-experiments
