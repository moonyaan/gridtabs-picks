# Osaurus

- **URL**: https://osaurus.ai
- **一句话**: 开源 macOS 原生 AI Agent 平台，完全本地离线，兼容 OpenAI/Anthropic/Ollama
- **详细说明**: Osaurus 是专为 Apple Silicon 打造的本地 AI Agent 平台，完全离线运行，支持切换 OpenAI、Anthropic、Ollama 等多个 LLM 后端，并兼容 MCP 协议。它让用户在 Mac 上构建和运行 AI Agent 时完全掌控数据隐私。
- **目标用户**: 注重隐私的 Mac 用户、AI 开发者、Apple Silicon 爱好者
- **视觉风格**: macOS 原生风格，简洁克制
- **主色调**: 系统级白色/灰色
- **氛围关键词**: 本地、隐私、开源、AI Agent、Apple Silicon
- **可归类方向**:
  - 常规: AI 工具、Mac 应用、自托管
  - 创意: 隐私优先 AI
