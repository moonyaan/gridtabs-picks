# Criblist

- **URL**: https://cribs.context.dev/
- **一句话**: 开源的 Tinder 式滑动找房工具，聚合 SF/NYC 实时公寓房源
- **详细说明**: Criblist 聚合旧金山、纽约多个租房平台（Craigslist、Brick+Timber、RentSFNow 等）的实时在租房源，做成一张张可滑动的卡片。设定预算、地段、必备条件后即可直接刷房源，免登录、完全开源，数据实时更新不含过期广告。
- **目标用户**: 正在旧金山/纽约找房的租客
- **视觉风格**: 极简现代科技感，中性色调，用城市地标 emoji（🌉🗽）做地域标识
- **主色调**: 中性灰白色调
- **氛围关键词**: 轻松随意、去繁就简、开发者友好、透明开源
- **可归类方向**:
  - 常规: 租房工具、生活效率工具
  - 创意: 把找房变成刷卡片
