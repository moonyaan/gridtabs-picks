# ThoughtDAG

- **URL**: https://chenxiachan.github.io/thoughtdag/
- **一句话**: 可编辑的上下文有向图工具，把 LLM 对话背后的思路分支变成可视化、可操作的图谱。
- **详细说明**: ThoughtDAG 认为"聊天界面隐藏了上下文，图谱才是真正的上下文"，将传递给大模型的信息以交互式图的形式展现，用户可以分支、合并、修剪和检查信息流，在生成前直接控制哪些内容真正进入模型输入，而不必重写整段对话。面向需要可复现性和精细控制 LLM 输入的研究者与知识工作者。
- **目标用户**: AI 研究者、知识工作者、需要复杂信息综合与迭代推理的重度 LLM 用户
- **视觉风格**: 极简克制，大量留白配合微妙渐变，排版层级分明现代，交互演示中用暖色（橙/琥珀）高亮可编辑元素，整体方法论感强、克制不花哨
- **主色调**: 灰阶为主，橙色/琥珀色作为交互强调色
- **氛围关键词**: 方法论、精确、透明、研究感、克制
- **可归类方向**:
  - 常规: AI 生产力工具 / LLM 上下文管理
  - 创意: 极简信息可视化美学
