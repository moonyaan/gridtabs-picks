# Cubicle

- **URL**: https://cubicle.run/
- **一句话**: 像素风办公室界面雇佣并实时观察 AI Agent（Claude Code 等）工作状态的工具
- **详细说明**: 用复古像素风格的虚拟办公室可视化展示 AI Agent 的工作进度，能看到谁在工作、谁卡住了、谁在开会。支持 Slack、Notion、GitHub 等常用办公软件集成，只读不干预，把枯燥的任务监控变成有趣的办公室模拟游戏。
- **目标用户**: 使用 Claude 等 AI Agent 的团队和开发者，需要可视化监控多个 Agent 任务状态
- **视觉风格**: 极简像素艺术风，复古数字感，办公室隐喻（桌子、椅子、会议室）
- **主色调**: 黑白为主，低饱和度点缀色
- **氛围关键词**: 复古像素、办公室隐喻、轻松幽默、专业感、游戏化
- **可归类方向**:
  - 常规: AI 工具可视化监控
  - 创意: 像素风游戏化界面设计
