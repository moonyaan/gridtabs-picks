# AgentKey

- **URL**: https://agentkey.app
- **一句话**: AI Agent 数据市场网关，单个 MCP 接入搜索/社媒/链上等 ~1800 个工具
- **详细说明**: AgentKey 是专为 AI Agent 设计的统一工具接入网关，通过单一 MCP server 连通约 1800 个数据源和工具，涵盖搜索引擎、社交媒体、区块链、金融、电商等，让 Claude、Cursor 等 Agent 无需逐个配置即可调用海量工具。
- **目标用户**: AI Agent 开发者、使用 Claude/Cursor 等工具的开发者、需要多数据源集成的团队
- **视觉风格**: 技术感强，以 MCP 协议和工具图标展示为核心
- **主色调**: 深色科技感配色
- **氛围关键词**: Agent、MCP、集成、数据市场、工具调用
- **可归类方向**:
  - 常规: AI 基础设施、开发者工具
  - 创意: AI 瑞士军刀
