# Blender Agent Bridge

- **URL**: https://www.producthunt.com/products/blender-agent-bridge
- **一句话**: 开源 MCP 桥接工具，让 Claude、Cursor 等 AI 助手操作 Blender 三维场景
- **详细说明**: 通过 Model Context Protocol 连接 Blender 与 AI 助手，让 AI agent 能够检视三维场景、收集视觉证据并协助建模工作流，同时保留艺术家对编辑、审批与付费生成功能的最终控制权，可集成 Meshy.ai、Tripo3D、Polyhaven 等服务。
- **目标用户**: 三维美术师、动画师、搭建 MCP 工作流的技术美术、希望保留创作主导权的工作室
- **视觉风格**: Blender 深色主题延续，工业灰配色，技术性视口界面截图
- **主色调**: 深灰配亮色高亮
- **氛围关键词**: 专业、协作、艺术家主导、AI 辅助
- **可归类方向**:
  - 常规: AI 创作辅助工具
  - 创意: 三维创作 AI 桥接
