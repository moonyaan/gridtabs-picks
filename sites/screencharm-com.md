# Screen Charm

- **URL**: https://screencharm.com/
- **一句话**: Mac端带自动缩放效果的屏幕录制与视频分享工具
- **详细说明**: Screen Charm 是一款 macOS 屏幕录制应用，可同时捕捉屏幕、摄像头、麦克风与系统音频，并自动添加缩放、光标平滑、动态模糊等专业效果，无需后期剪辑即可导出 4K MP4 或分享链接。
- **目标用户**: 开发者与工程师（产品演示）、课程创作者、SaaS 创始人及初创团队、教程与发布视频内容创作者
- **视觉风格**: 极简现代，符合 macOS 设计语言，排版干净、留白充分，追求"默认即电影感"的精致输出
- **主色调**: 黑白灰中性色为主，点缀色克制
- **氛围关键词**: 精致、电影感、流畅、专业不复杂、自信从容
- **可归类方向**:
  - 常规: productivity / creator-tools
  - 创意: mac-native-craft
