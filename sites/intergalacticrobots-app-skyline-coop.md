# Skyline Co-op

- **URL**: https://intergalacticrobots.app/skyline-coop/
- **一句话**: 类 SimTower 的高楼建造模拟游戏，但玩家是被选举出的管理者而非逐利房东。
- **详细说明**: 把经典高楼模拟游戏的"地主"设定改写为"合作社"：住户和商户共同拥有大楼，玩家作为被选举的管理者需要平衡居民满意度而非单纯追求利润，围绕集体所有制展开的另类经营模拟。
- **目标用户**: 策略游戏爱好者、对另类经济制度和合作管理模拟感兴趣的人
- **视觉风格**: 复古 SimTower 风格的极简像素界面，功能性 UI
- **主色调**: 中性色调
- **氛围关键词**: 深思、教育性、真诚、社会责任、另类经营
- **可归类方向**:
  - 常规: 模拟游戏、策略游戏
  - 创意: 乌托邦建筑师、反资本主义游戏
