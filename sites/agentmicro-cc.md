# AgentMicro

- **URL**: https://agentmicro.cc/
- **一句话**: 菜单栏小工具，实时显示多个 Codex AI 编程任务的进度，不用来回切窗口。
- **详细说明**: 免费开源的 macOS 菜单栏应用，显示思考中、有未读结果、等待输入、出错、空闲五种状态，点击可直接跳转到对应 Codex 会话。强调本地优先，只读取本地会话元数据，绝不上传代码或对话内容。
- **目标用户**: 使用 Codex/AI 编程助手的开发者，多任务并行开发者
- **视觉风格**: 简洁浅色系，macOS 原生观感
- **主色调**: 浅色中性调
- **氛围关键词**: 本地优先、开发者效率、AI 编程配套、隐私友好
- **可归类方向**:
  - 常规: 开发者工具、AI 编程配套
  - 创意: 极简效率、菜单栏美学
