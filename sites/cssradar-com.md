# CSS Radar

- **URL**: https://cssradar.com
- **一句话**: 扫描网站代码，找出可以用现代CSS替代的旧写法
- **详细说明**: CSS Radar 会扫描公开网页，识别出可以用现代 CSS/HTML 原生特性替代的自定义代码，并给出带浏览器兼容性数据支撑的具体建议。适合用于渐进式代码现代化，而非一键自动改写。
- **目标用户**: 维护老旧代码的前端团队、准备改版的设计师、独立开发者审查自己的产品
- **视觉风格**: 极简技术文档风，排版清晰，结构分明，注重信息可读性而非视觉装饰
- **主色调**: 中性色调（白/浅灰背景），代码块与交互元素点缀色
- **氛围关键词**: 实用、证据驱动、克制、开发者友好、务实
- **可归类方向**:
  - 常规: developer-tools / code-quality-tools
  - 创意: swiss-army-knife-sites
