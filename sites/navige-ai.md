# Navige

- **URL**: https://navige.ai
- **一句话**: 介于 AI agent 和大模型之间的成本控制层，自动路由模型、拦截浪费调用并复用已验证结果
- **详细说明**: Navige 位于 AI agent 与其调用的模型/工具之间，把每次调用路由到合适的模型，拦截无效调用，并复用已验证过的答案来降低 AI 支出，而不改变输出结果。面向负责 AI agent 和 LLM 工作负载programmatic 支出的工程、平台和财务负责人，页面提供交互式支出计算器。
- **目标用户**: 运行 AI agent 和 LLM 工作负载的团队，尤其是负责控制 AI 支出的工程、平台和财务负责人
- **视觉风格**: 短标题加简短标签的结构化布局，带交互式支出计算器
- **主色调**: 未知
- **氛围关键词**: 冷静、精确、高效、稳健、务实、可控
- **可归类方向**:
  - 常规：AI 基础设施工具、成本优化工具、开发者工具
  - 创意：AI 支出可视化、务实工程美学
