# Sygal

- **URL**: https://sygal.app
- **一句话**: 本地运行的文档转换工具，把 PDF、文档、网页、YouTube 链接批量转换成干净的 Markdown 和结构化 JSON
- **详细说明**: Sygal 可将 PDF、Word/Excel 文件、图片扫描件、网页和 YouTube 链接在本机转换为干净的 Markdown 和 JSON，面向 AI 构建者用于 RAG 流程和向量库准备，也适合处理法律、会计、医疗等敏感文档的专业人士。同时提供命令行工具 sygal-cli，方便脚本和 Agent 流水线调用。
- **目标用户**: 构建 RAG/AI 应用的开发者、处理敏感文档的专业人士（法律、会计、HR、医疗）、想建立本地可搜索文档库的普通用户
- **视觉风格**: 深色主题界面（dark mode 素材），应用截图展示文档库、预览和编辑器界面
- **主色调**: 深色系（具体色值未知）
- **氛围关键词**: 私密、本地化、干净、精确、可信赖、一次性处理
- **可归类方向**:
  - 常规：AI 工具、文档处理、开发者工具、RAG 工具链
  - 创意：本地优先设计、隐私工具美学
