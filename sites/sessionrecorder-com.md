# Session Recorder

- **URL**: https://sessionrecorder.com/
- **一句话**: 为音乐制作人持续录制电脑音频的"永不错过灵感"工具
- **详细说明**: Session Recorder 是一款 macOS 常驻录音应用，实时缓存扬声器输出的立体声混音，免费版保留 30 分钟滚动缓冲区，Pro 版可完整保存并支持 DAW 插件（AU/VST3）集成与多格式片段导出。专为在正式录音之外捕捉即兴创作瞬间而设计。
- **目标用户**: 音乐制作人、录音室工作者、使用 Logic/Live/Reaper/Cubase 等 DAW 的创作者
- **视觉风格**: 极简复古，以老式盘式录音机为视觉隐喻，留白充足，层次清晰
- **主色调**: 米白背景 + 深色文字 + 红色 REC 指示点缀
- **氛围关键词**: 怀旧、可靠、灵感守护、温情、复古浪漫
- **可归类方向**:
  - 常规: creator-tools / music-production
  - 创意: weekend-websites-worth-opening
