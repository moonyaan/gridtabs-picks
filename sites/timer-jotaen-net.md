# Timer

- **URL**: https://timer.jotaen.net
- **一句话**: 可编程的健身或拉伸训练计时器网页应用
- **详细说明**: Timer 是一个面向健身场景的可编程计时器，用户可自定义每个训练环节的时长和顺序，适合力量训练、拉伸等分阶段的训练流程，无需下载 App 即可在网页直接使用。
- **目标用户**: 健身爱好者、需要间歇计时的运动训练者
- **视觉风格**: 极简朴素，功能优先，无多余装饰
- **主色调**: 推测为简洁黑白或低饱和色调（未能完全确认）
- **氛围关键词**: 实用、朴素、专注、轻量
- **可归类方向**:
  - 常规: productivity / utilities
  - 创意: minimal-life-tools
