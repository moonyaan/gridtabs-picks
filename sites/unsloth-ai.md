# Unsloth Desktop

- **URL**: https://unsloth.ai
- **一句话**: 可在本地桌面运行和训练AI模型的桌面应用
- **详细说明**: Unsloth 让用户完全本地化地运行、训练和连接文本、图像、视频、音频等各类 AI 模型，支持将 Claude Code、Codex 等智能体连接到本地模型，并提供沙盒代码执行能力。完全免费且无需依赖云端。
- **目标用户**: 开发者、AI 爱好者，尤其是注重隐私和希望摆脱云端依赖的 AI 编程工具用户
- **视觉风格**: 现代深色系界面，几何图形与渐变点缀，卡片式布局，科技感与易用性并重
- **主色调**: 深炭灰背景 + 青蓝色高亮 + 白/浅灰文字 + 少量翠绿与紫色渐变
- **氛围关键词**: 自由、掌控力、本地化、专业、前沿
- **可归类方向**:
  - 常规: ai-tools / developer-tools
  - 创意: local-first-tech
