# GlassKit

- **URL**: https://glasskit.app
- **一句话**: 为 Meta Ray-Ban 智能眼镜开发应用的 React 组件库和 AI 构建工具
- **详细说明**: GlassKit 是首个专门面向 Meta Ray-Ban Display 的开发者工具链。眼镜 App 本质是标准 HTML/CSS/JS 网页，但渲染在 600×600 的镜片上，用神经臂带导航。GlassKit UI 提供 44 个免费 React 组件，GlassKit Studio 用文字提示词直接生成可发布的眼镜 App。
- **目标用户**: 前端开发者、想进入穿戴设备领域的独立开发者、AR 应用探索者
- **视觉风格**: 现代开发者工具审美，清洁简约，带硬件产品感
- **主色调**: 黑白、深蓝、科技感渐变
- **氛围关键词**: 前沿、新平台、开发者、穿戴计算、2026 先行者
- **可归类方向**:
  - 常规: 穿戴设备开发工具 / AR 应用生态
  - 创意: "下一个浏览器可能长在你脸上——先来占个坑"
