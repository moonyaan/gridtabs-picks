# ITom — Creative 3D Portfolio

- **URL**: https://itomdev.com/
- **一句话**: 纸张撕裂展开成无限画廊长廊的手绘质感 3D 作品集
- **详细说明**: 波兰创意开发者 Tomasz "ITom" Szmajda 的获奖作品集网站，开场是一张 2D 纸张用 GSAP 驱动的 SVG 动画「撕裂」展开进入 3D 空间，随后访客穿行在一条无限延伸的手绘素描风格美术馆长廊，画框中的作品通过自定义 WebGL shader 逐渐「显影」上色。还有一个可拖拽旋转的物理效果显示器塔楼房间。
- **目标用户**: 创意工作室、寻找高端交互网站灵感的品牌方、前端创意开发者
- **视觉风格**: 手绘素描质感，暖色蛋壳背景，2D 转 3D 的戏剧性过渡
- **主色调**: 暖米白/蛋壳色背景，铅笔素描线条
- **氛围关键词**: 手工感、温暖、沉浸式画廊、创意编程、获奖设计
- **可归类方向**:
  - 常规: 创意开发者作品集
  - 创意: 手绘风格 3D 网站、沉浸式叙事体验
