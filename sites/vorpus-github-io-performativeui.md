# Performative UI

- **URL**: https://vorpus.github.io/performativeUI/
- **一句话**: 讽刺当下花哨但无意义 UI 设计套路的 React 组件展示库，兼具幽默和教学。
- **详细说明**: 收集并复刻当代产品设计中常见的"表演性"UI 模式（过度动画、虚假进度、无意义微交互等），以 React 组件形式展示，既是一份讽刺当下设计流行病的作品，也可作为反面教材学习案例。
- **目标用户**: 前端开发者、UI/UX 设计师、对设计批评感兴趣的人
- **视觉风格**: 刻意夸张的动效示例，展示"过度设计"的反讽美学
- **主色调**: 未明确
- **氛围关键词**: 讽刺、设计批评、幽默、开发者向
- **可归类方向**:
  - 常规: 开发者工具、组件库
  - 创意: 设计讽刺与批评
