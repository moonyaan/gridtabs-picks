# WebGL Glass Xylophone

- **URL**: https://tympanus.net/Tutorials/Xylophone/
- **一句话**: 划过屏幕就能演奏的无限循环玻璃木琴，Three.js 打造的视听装置
- **详细说明**: Codrops 出品的 Three.js 实验作品：64 根磨砂玻璃琴条沿螺旋无限向上滚动排列，鼠标划过时琴条会敲响对应音符、像被敲中的编钟一样摆动，并涌起彩色波纹。融合了实例化渲染、流体模拟和纯 shader 打造的玻璃质感，视听效果治愈梦幻。
- **目标用户**: 创意开发者、WebGL/Three.js 爱好者、喜欢沉浸式音画互动体验的设计师
- **视觉风格**: 磨砂玻璃质感，螺旋无限滚动结构，光影通透
- **主色调**: 玻璃透明基调，触碰时泛起彩虹色波纹
- **氛围关键词**: 治愈、光影通透、音画同步、无限循环、创意编程
- **可归类方向**:
  - 常规: 创意编程作品、WebGL 实验
  - 创意: 音画互动装置、生成艺术玩具
