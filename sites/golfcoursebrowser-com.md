# Golf Course Browser

- **URL**: https://golfcoursebrowser.com
- **一句话**: 一位高尔夫爱好者独立绘制的美国及加拿大 18000+ 高尔夫球场交互地图。
- **详细说明**: 可按地理位置、公开/私人性质、洞数、设施（如练习场）筛选球场，查看详情并提交更正或新增。地图优先、去装饰化，强调"免费、一个人做的"这种朴素可信感。
- **目标用户**: 高尔夫球手、旅行打球爱好者、想探索周边球场的玩家
- **视觉风格**: 极简浅色地图界面，高尔夫图标点缀，功能优先
- **主色调**: 浅灰、草绿、白色
- **氛围关键词**: 实用、亲切、业余爱好者精神、地图控
- **可归类方向**:
  - 常规: 地图工具、运动爱好
  - 创意: 独立地图控、一人之力的百科
