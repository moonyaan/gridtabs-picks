# Nimbus

- **URL**: https://usenimbus.app
- **一句话**: 受 Claude Code 启发的 AI 原生浏览器，用自然语言描述任务即可自动完成多步骤网页操作
- **详细说明**: Nimbus 是一款内嵌 AI 代理的新型浏览器，用户可以用自然语言告诉浏览器要做什么，AI 自动控制标签页完成表单填写、信息搜集、跨站操作等复杂任务。代表了「对话式浏览」的新范式，灵感来自 Claude Code 的命令行代理模式。
- **目标用户**: 希望自动化日常网页任务的用户、重复性网页操作的效率追求者
- **视觉风格**: 现代浏览器界面 + AI 对话面板
- **主色调**: 深色系，专业感
- **氛围关键词**: AI 浏览器、自动化、自然语言、多步操作、新范式
- **可归类方向**:
  - 常规: AI 浏览器
  - 创意: ai-no-code-2026, swiss-army-knife-sites
