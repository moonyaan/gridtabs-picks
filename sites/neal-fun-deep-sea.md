# The Deep Sea

- **URL**: https://neal.fun/deep-sea/
- **一句话**: 从海面一路下滑到挑战者深渊的单页滚动可视化，沿途标注各深度的真实海洋生物。
- **详细说明**: Neal Agarwal 出品的经典交互式单页项目，用户持续向下滚动即可从海平面一直"潜"到马里亚纳海沟挑战者深渊（约 10,924 米），背景随深度渐变越来越暗的蓝色，每个深度层都配有对应真实生物的手绘插图和简短说明。没有复杂交互，纯靠滚动节奏和色彩渐变营造沉浸式的深潜体验，上线多年后依然被反复提及为"互联网最治愈的网页之一"。
- **目标用户**: 对海洋生物和深海好奇的人、喜欢氛围感网页玩具的人、科普教育者
- **视觉风格**: 整页贯穿蓝色渐变——从海面的明亮天蓝，逐层加深为中蓝、深蓝、藏青，最终接近黑色，模拟真实光线随深度递减的效果，插图风格为简洁手绘
- **主色调**: 蓝色渐变（浅天蓝 → 深蓝 → 藏青黑），几乎全程蓝色主导
- **氛围关键词**: 沉浸、治愈、深潜、科普、渐变美学、滚动叙事
- **可归类方向**:
  - 常规: 科学可视化、科普教育
  - 创意: 蓝色星球、深海诗学、滚动叙事经典
