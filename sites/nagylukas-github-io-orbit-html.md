# Orbit

- **URL**: https://nagylukas.github.io/orbit.html
- **一句话**: 用 AR 把手机变成实时卫星追踪器，抬头一扫就知道头顶飞过什么。
- **详细说明**: iOS 增强现实应用落地页，摄像头对准天空即可识别国际空间站、上万颗卫星、行星和星座位置，追踪超过 1.5 万个轨道物体，提供过境预测和 AI 太空问答，无需账号且强调匿名隐私。
- **目标用户**: 天文爱好者、AR 应用尝鲜者、太空迷
- **视觉风格**: 简洁排版，大量留白，贴近 Apple 设计语言
- **主色调**: 简约现代色调
- **氛围关键词**: 增强现实、太空探索、隐私优先、抬头即用
- **可归类方向**:
  - 常规: AR 应用、天文工具
  - 创意: 太空探索、抬头看天、科技感
