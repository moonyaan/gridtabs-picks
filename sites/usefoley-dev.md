# Foley

- **URL**: https://usefoley.dev
- **一句话**: 无需任何音频文件，纯代码实时合成 28 种交互音效的轻量 JS 库。
- **详细说明**: 零依赖的 Web Audio 库，7 大类共 28 种预设交互音效（点击、悬停、成功、错误提示音等），全部实时计算生成而非播放音频文件。内置浏览器端声音设计器可调 4 个参数自定义音色，支持导出 wav 或 JSON 音色包，兼容原生 JS/React/Vue，还有 4 套主题一键切换全站音色。
- **目标用户**: 前端开发者、注重产品音效体验的团队
- **视觉风格**: 深色背景+等宽字体的技术极客风，页面本身可点击试听
- **主色调**: 深色调
- **氛围关键词**: 开发者工具、极客幽默、声音设计、零依赖
- **可归类方向**:
  - 常规: 开发者工具、音频库
  - 创意: 声音设计、极客玩具、交互反馈美学
