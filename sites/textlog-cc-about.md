# textlog

- **URL**: https://textlog.cc/about
- **一句话**: 纯文本、无 JavaScript 的极简微博客平台，280 字符发短文。
- **详细说明**: 反算法、反流量诱导的社交平台，主打"安静的角落"，用户发布不超过 280 字符的短文，可关注他人和话题标签。刻意做小、不做增长套路，强调真诚交流和社区责任感。
- **目标用户**: 厌倦了表演式社交媒体、想找安静角落写作和交流的人
- **视觉风格**: 极简纯文本界面，无 JS，不追求视觉丰富度，专注文字本身
- **主色调**: 黑白灰为主的朴素配色
- **氛围关键词**: 沉静、反算法、克制、社区、真诚
- **可归类方向**:
  - 常规: 社交平台、微博客、极简工具
  - 创意: 数字疗愈、慢社交、反主流
