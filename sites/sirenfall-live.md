# Sirenfall

- **URL**: https://sirenfall.live
- **一句话**: 在浏览器里拉响一台复古民防警报器，沉浸在雨夜掩体的末日氛围中
- **详细说明**: 一个免费的浏览器互动场景，用户拉动虚拟断路器拉杆即可激活合成警报声——用 Web Audio 实时生成 515Hz 与 618Hz 双音调、每 15 秒扫频一次的经典警报音效，而非播放录音。场景背景是俯瞰雨夜城市的地下掩体，配有雷雨声、CRT 显示器和百叶窗等互动元素，无需登录安装。
- **目标用户**: 复古美学爱好者、音效/氛围设计师、末日/冷战美学粉丝
- **视觉风格**: 复古工业风，雨夜掩体场景，CRT 显示器质感，昏暗压抑的沉浸式氛围
- **主色调**: 冷色调雨夜蓝灰，暖色警报灯点缀
- **氛围关键词**: 复古警报、末日感、冷战怀旧、沉浸式音景、雨夜氛围
- **可归类方向**:
  - 常规: 互动音景体验
  - 创意: 复古末日氛围装置
