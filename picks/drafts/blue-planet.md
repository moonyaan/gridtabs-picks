# Everything on This List Is Just... Blue

A map tool, a deep-sea scroll, a task tracker — zero functional overlap. Eight sites united by one choice: someone picked blue and committed.

# 这八个网站，唯一的共同点就是蓝

这次真的没有别的标准，纯粹是看哪个网站最蓝就挑哪个。地图工具、深海滚动页、任务管理器，功能完全不搭边，放在一起只因为它们都把蓝色用到了极致。

## Sites

### Atlas
- **URL**: https://atlas.co
- **EN**: Saturated blue (#228be6) covers every panel and hover state — blue as the whole personality here.
- **ZH**: 饱和度刚好的蓝（#228be6）铺满每个面板和悬浮状态——不是点缀色，是整个产品的人格设定。

### Blue Ball Machine
- **URL**: https://www.chubbybots.com/
- **EN**: A blue ball loops endlessly through a Rube Goldberg machine — the color is the entire point.
- **ZH**: 一颗蓝色小球在鲁布·戈德堡机关里无限循环，颜色就是全部重点，看十秒就懂。

### Xikipedia
- **URL**: https://xikipedia.org
- **EN**: Electric blue (#2cafff) on a near-black background — contrast that makes the color jump out.
- **ZH**: 亮蓝（#2cafff）配几乎纯黑的背景，这种对比让颜色从"存在"变成"跳出来"。

### Super Productivity
- **URL**: https://super-productivity.com
- **EN**: The blue (#4385f4) stays just as present in dark mode — most apps lose their color there.
- **ZH**: 切换明暗模式，那个蓝（#4385f4）两边都稳——多数应用进暗色模式配色就散了。

### The Deep Sea
- **URL**: https://neal.fun/deep-sea/
- **EN**: Scroll from sky-blue surface to near-black navy — ten thousand meters, blue the whole way down.
- **ZH**: 从海面亮天蓝一路滚到接近黑色的藏青，一万米全程没离开过蓝色。

### FileFlan
- **URL**: https://fileflan.com
- **EN**: No illustrations, no flourish — this file tool's flat blue carries the whole page by itself.
- **ZH**: 文件传输工具，视觉上没什么可卖的，一块纯蓝色就扛起了整个页面。

### Flowstep
- **URL**: https://flowstep.ai
- **EN**: This AI tool builds UI from a sentence, in a blue so consistent even its demo shots match the site.
- **ZH**: 一句话生成 UI 的 AI 设计工具，产品内部演示截图都和官网用同一种蓝。

### TaskWave
- **URL**: https://taskwave.online
- **EN**: A free, self-hosted Asana alternative — one soft blue does the "trustworthy SaaS" work alone.
- **ZH**: 免费自部署的 Asana 替代品，一块干净柔和的蓝色就说清了"值得信赖"这件事。
